# 일반음식점 계약 fixture

2026-09-07 공식 페이지 https://www.data.go.kr/data/15154916/openapi.do 내장 Swagger와 제한된 실제 응답의 구조를 확인했다. page.json은 테스트를 위해 새로 작성한 합성 자료다. 실제 업소명·전화번호·주소·외부 ID·인증키를 복제하지 않는다.

실제 원문은 저장소에 커밋하지 않았다. 실제 응답에서 확인된 날짜 표기와 문서상 날짜 표기를 각각 넣었다. TELNO는 사용자 요구에 따라 업소 연락처로 사용하며 테스트 번호는 실제 연락을 위한 값이 아니다. 미지 필드는 저장에서 제외하고 필수 envelope 구조 변경은 계약 오류로 처리한다.

fixture 성공은 외부 호출·저장 성공의 증거가 아니다. 실제 호출 및 서비스 저장 여부는 docs/integrations-status.md에서 별도로 기록한다.
