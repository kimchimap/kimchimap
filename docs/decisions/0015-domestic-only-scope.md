# 국내산 사용 항목이 있는 업소의 수집·공개

2026-09-08 사용자가 서비스 범위를 명확히 했다. 전체 업소를 수집·공개한 뒤 원산지를 붙이는 서비스가 아니다. 국내산 사용 항목이 확인된 업소만 수집·공개하며 등록되지 않은 업소는 사용자가 제보한다. 이전 구현의 일반음식점 기본자료 선수집은 요구사항을 잘못 해석한 결과다.

공개 자격은 승인·유효·공개 가능한 특정 메뉴/용도의 국내산 식재료 기록이 최소 하나 있는지로 결정한다. 미확인·혼합·분쟁·만료만 있는 업소는 자격이 없다. 조건이 없는 검색·직접 상세·즐겨찾기에도 같은 기준을 적용한다. 다른 식재료의 수입산 기록이 있어도 확인된 국내산 항목이 있으면 해당 항목 범위로 소개할 수 있다. 지정 사실을 모든 원재료로 확대하지 않는다.

일반음식점 API에는 원산지 필드가 없다. 현재 전체 목록 수집은 중단하며 과거 저장된 기본자료는 공개하지 않는다. 적격 업소의 식별자별 보완 조회가 실제 명세로 확인되면 별도 경계를 구현한다. 허가된 국내산 원산지 소스가 아직 없음을 그대로 기록한다.

미등록 업소는 사진·업소 정보·국내산 항목 제보를 검수 대기 자료로 받는다. 제출만으로 공개하지 않으며 관리자 확인 후 공개 자격을 충족해야 지도에 표시한다. 이 흐름을 공개 자격 수정에 이어 구현한다.
