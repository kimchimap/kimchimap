# ADR 0001: 이번 단계는 실행 하네스만

상태: 채택, 2026-09-07.
사용자의 첫 문장에 있는 실제 구현 보류 지시를 현재 범위로 해석한다. 나머지 전체 서비스 요구는 후속 개발의 수용 기준으로 보존한다. 서버·화면·도메인·수집기를 만들지 않고 실행 도구·인프라·Git 검사와 설계를 만든다.

미구현 명령은 exit 2로 필요한 파일/단계를 안내한다. verify-harness는 하네스만, verify는 서비스 필수 검사까지 실행하여 미구현이면 실패한다. 이름만 같은 성공 stub, skip으로 완료를 가장하지 않는다. 애플리케이션 파일을 추가하는 단계에서 기존 dispatch 대상 task를 구현해야 한다.
