# ADR 0004: 작업 단위 검증과 전체 완료 분리

상태: 채택. 사용자가 작업별 구현·검증·dev PR 병합·브랜치 정리의 반복을 요청했다.

전체 verify는 모든 후속 기능까지 포함하여 미구현 시 계속 실패한다. 현재 작업을 검증할 verify-unit은 코드에 등록된 수용 기준과 검사 명령을 실행하며 미구현 후속 목록을 표시한다. 기존 테스트 삭제·skip·린트 해제 없이 현재 구현 전체 회귀를 포함한다. PR 준비에는 --unit을 명시하고 전체 서비스 완료로 보고하지 않는다.

application-foundation은 환경·하네스·형식·타입·단위·실제 DB/Redis·OpenAPI 계약·모바일/PC E2E·양쪽 build를 모두 요구한다. 외부 소스 계약/수집과 공간 성능은 도메인 구현 전이라 여전히 미구현이다. 후속 단위는 이전 단위 검사를 포함하고 새 수용 테스트를 추가해야 한다. 검사 조정은 해당 PR에서 이유와 영향을 기록한다.
