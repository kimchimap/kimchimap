# 전국 김치 지도와 좋아요로 제품 범위 확정

날짜: 2026-11-12. 상태: 사용자 확정 요구 반영.

범용 원재료 검색 제품에서 배추·고춧가루·두 재료의 국내산 여부를 찾는 전국 김치 지도로 좁힌다. 정규화된 원산지·증빙·검수 모델은 유지하되 사용자 화면에 불필요한 범용 선택을 제거한다. 신규 가게는 지도 위치 선택과 표시판 사진 제보, 관리자 승인으로 공개한다. 기존 정보 오류 신고는 등록 제보와 다른 처리 목적을 가진다.

즐겨찾기를 좋아요로 통합한다. 별도 저장소를 병설하지 않고 V12에서 테이블을 이름 변경한다. 공개 합계는 회원 식별자를 포함하지 않으며 비공개 업소에는 제공하지 않는다. 회원·업소 복합 기본 키와 멱등 PUT/DELETE를 유지해 재전송으로 수가 증가하지 않는다. 계산된 합계를 원본으로 사용하여 별도 카운터의 불일치를 피한다.

외부 지정의 인증 날짜는 실제 지정일, 제보의 인증 날짜는 실제 승인일이다. 두 근거의 이름을 함께 표시한다. 수집 성공일을 인증 날짜로 치환하지 않는다. 외부 지정 대상에는 95% 기준의 고속도로 휴게소 예외가 있으므로 지정 사실만으로 두 원재료 모두 국내산이라고 생성하지 않는다. 일반 음식점의 100% 기준도 지정품목과 적용 범위가 확인되어야 검색 근거로 연결한다.

기존 Flyway 파일과 검증 이력은 레거시 실행 기능과 구분한다. 이미 적용된 마이그레이션을 삭제하지 않고 후속 변경으로 폐기한다. 기존 사용자 제출본·감사는 보존하고, 불필요한 외부 업소 자료는 관련 참조를 확인한 뒤 대상 소스에 한정해 정리한다.
