# 원산지 정정과 상충 재판정

확인일: 2026-09-08. 상태: 채택.

정정은 동일 메뉴·용도·식재료의 승인 기록에서 잘못된 대상을 명시하여 철회하는 방식이다. 원문·국가 구성·관찰일은 수정하지 않는다. 새 내용이나 증빙은 제보·검수로 새 불변 기록을 추가한다. 기존 정확한 기록과 상충하던 잘못된 기록만 제외하면 남은 근거로 다시 판정하며 전부 철회하면 공개 가능한 정보가 없는 상태가 된다.

메뉴 행과 현재 공개 판정 행을 잠근 뒤 expectedVersion을 검사한다. 다른 그룹의 기록·이미 철회한 기록·중복 선택은 거부한다. 철회, 공개 재판정과 불변 정정 감사를 하나의 트랜잭션에서 처리한다. 검수 승인과 정정은 같은 메뉴 잠금·동일 공개 판정 코드를 사용한다. 과거 정정이 이후 새 상충 기록을 자동으로 무시하지 않는다.

관리자 목록은 안정적인 보조 키와 20개 기본 페이지를 사용한다. 조회 이동 상한에 도달하면 truncated를 반환하며 전체 결과처럼 표시하지 않는다. 정정 상세는 일관된 DB 읽기 스냅샷을 사용한다. 기록이 2천 건을 넘으면 일부만 읽어 판정하지 않고 거부하며 별도 이력 관리가 필요하다. 최근 정정 감사는 최대 100건임을 화면에 표시한다.

권한과 버전은 서버에서 검사한다. UI 접근 경계는 공통 MemberGate로 재사용하며 이를 서버 인가의 대체로 보지 않는다. 관리자 화면은 증빙이 있는 제보 검수 화면으로 연결하고 실제 납품 검증으로 안내하지 않는다.

실제 HTTP 검색 검증 중 혼합 포함 옵션 생략이 Jackson의 원시형 처리로 거부되는 문제를 발견했다. nullable 입력을 명시적으로 false로 정규화하여 문서의 기본값과 일치시켰다. 좌표 필수 검증과 혼합의 순수 국내산 매칭 금지는 유지한다. 검색 응답 200을 확인한 뒤 정정 전후 결과를 검증한다.
