# 명시적으로 확인한 김치 품목만 공개

날짜: 2026-11-12. 사용자 확정 범위: 대한민국 전국 국산 배추·국산 고춧가루·둘 다 국산 김치 지도.

이전 공개 함수는 국내산 식재료 하나면 업소 공개 자격을 부여했다. 이는 국내산 쌀만 있는 업소도 노출하므로 확정 범위와 맞지 않는다. 품목 이름에 김치가 들어간다는 이유만으로 분류하지 않는다.

V16은 serving_scope.food_kind를 UNKNOWN/KIMCHI로 구분한다. 기존 행은 UNKNOWN으로 남기며 이전 관찰·검수 이력을 바꾸지 않는다. 이후 승인 요청은 관리자의 kimchiReviewed=true를 요구하고 새 품목을 KIMCHI로 생성한다. 기존 품목 병합은 KIMCHI로 확인된 동일 업소·용도만 허용한다.

공개 자격은 같은 김치 품목 안의 배추 또는 고춧가루에 유효하고 공개 가능한 순수 국내산 근거가 있어야 한다. 혼합·상충·만료·철회·미확인과 다른 식재료는 자격을 부여하지 않는다. 두 재료 검색은 기존 같은 품목 AND 조건을 유지한다. 지도·직접 상세·좋아요는 같은 공개 함수를 사용한다.

기존 UNKNOWN 품목은 공개되지 않는다. 이름을 이용한 일괄 보정이나 과거 승인 시각을 새 승인 시각으로 바꾸지 않는다. 기존 자료의 명시적인 재분류 관리 절차는 후속 작업이다. 현재 실제 외부 원산지 초기 자료는 확보하지 않았다.

테스트 fixture는 일반 쌀 대신 별도의 김치 고춧가루를 공개 자격 보조 근거로 사용한다. 검수 테스트 집계는 실제 검수 대상인 배추로 지정한다. 쌀만 국내산·분류 미확인 배추의 비공개 회귀를 별도로 유지해 검사 범위를 줄이지 않는다.
