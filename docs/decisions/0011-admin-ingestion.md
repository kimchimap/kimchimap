# 관리자 수집과 서버 권한 관리

확인일: 2026-09-08. 상태: 채택.

관리자 재실행은 허가된 실제 일반음식점 어댑터에만 제공한다. 소스 식별자·인증키 설정·수집/재게시 조건을 확인하고 최대 100페이지 예산과 사유를 받는다. 기본 화면 예산은 2페이지다. 인증키 값은 응답에 포함하지 않는다. 관리자 API의 작업 DTO는 lease owner와 fencing token을 제외한다.

UUID 요청 키와 본문 해시는 24시간 보관한다. 사용자별 DB 트랜잭션 잠금 아래 요청 키·시간당 최대 10회·감사 기록을 검사한다. 같은 키의 재전송은 동일 작업을 반환하고 일부 처리 작업의 예산을 다시 늘리지 않는다. 새 키로 재개하면 기존 작업의 시점·페이지 크기를 유지한다. 감사 이력은 불변이다. 만료 요청 키는 한 시간마다 최대 1천 개씩 정리하며 감사 기록을 삭제하지 않는다.

명시적으로 접수된 작업과 정기 수집 생성을 분리했다. 실행기는 한 번에 한 페이지를 별도 단일 스레드에서 처리하며 중복 실행 안전성은 기존 DB lease/fencing이 담당한다. 정기 수집은 계속 기본 꺼짐이다. 테스트 프로필에서는 자동 실행기를 끄고 실제 DB와 통제된 외부 응답으로 작업 처리를 검증한다. 사용자 요청 스레드에서 외부 수집을 실행하지 않는다.

기존 사진 정리 스케줄이 수집 스케줄 활성화에 종속된 문제를 수정했다. 스케줄 기반 기능은 항상 등록하고 정기 외부 수집 여부는 수집기 내부에서만 판단한다. 기본 꺼진 정기 수집을 켜지 않아도 임시 사진·만료 요청 정리가 동작한다.

서버 회원 권한 명령은 기본 변경 계획만 출력한다. 활성 회원의 USER/ADMIN 변경만 지원하고 명시적 apply가 있어야 변경한다. 서버 OS 실행자와 사유를 감사에 남긴다. 대상 회원이 없거나 정지·탈퇴 상태이면 변경하지 않는다. 최초 가입자 승격이나 HTTP 인증 우회는 없다. 도구 구현 자체는 실제 사용자 관리자 승격 승인이 아니다.

후속 범위: 관리자 원산지 정정·지정 정보·업소 매칭 검토와 전체 지도 UI, 운영 보관 정책. 협회 데이터 허가가 없어 해당 수집을 구현 완료나 실연동 성공으로 표시하지 않는다.
