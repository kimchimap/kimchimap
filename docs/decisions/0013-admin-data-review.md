# 지정 정보와 업소 매칭 검토

확인일: 2026-09-08. 상태: 구현·전체 자동 검증 통과.

일반음식점 기본정보 이용 허가는 지정 제도 데이터까지 허가하지 않는다. 소스의 지정 이용 범위는 기본 거부한다. 별도 허가가 확인된 소스에만 생성·수정을 허용하고 공개 조회에서도 현재 허가를 검사한다. 실제 협회 허가는 아직 없다. 제도 이름·적용 품목·기준 원문·날짜를 보존하며 지정으로 식재료 원산지 기록을 생성하지 않는다. 수정은 현재 버전과 관리자 사유를 요구하고 모든 스냅샷을 불변 기록한다.

애매한 업소는 수집 당시의 정규화 관찰본과 후보로 검토한다. 관찰본이 없는 과거 후보는 다음 허용 수집까지 확정할 수 없다. 같은 이름만으로 병합하지 않으며 관리자가 후보 연결 또는 별도 지점 생성을 선택한다. 동일 출처의 서로 다른 외부 식별자는 같은 지점에 연결하지 않는다. 외부 식별자 잠금과 대상 업소 행 잠금 뒤 기존 연결을 재조회해 서로 다른 관찰본의 동시 연결도 거부한다. 정정된 업소 필드는 기존 수동 정정 정책을 유지한다.

수집 작업 → 외부 식별자 → 관찰본 순서로 잠근다. 검토가 대기하는 동안 관찰본의 작업이 바뀌면 최신 자료 확인을 요구한다. 이 순서는 수집의 작업 행 잠금과 검토 감사의 외래키 검사가 반대 순서로 기다리는 상황을 피한다. [PostgreSQL 18 잠금 문서](https://www.postgresql.org/docs/18/explicit-locking.html)의 행 잠금 충돌 관계와 일관된 잠금 순서를 따른다. 검수 상태·업소 연결·감사는 같은 트랜잭션이다.

수집 성공 시각은 관찰본의 원래 시각을 사용한다. 검토 후 원래 작업의 격리 건수는 당시의 실행 결과로 남기고 별도 검수 상태를 갱신한다. 관리자 목록은 최근 지정 50개·대기 매칭 50개이며 화면에 상한을 명시한다. 지정 이력 상세는 최근 100개를 표시하고 DB 이력은 삭제하지 않는다.
