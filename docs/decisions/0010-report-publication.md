# 제보 제출본과 검수 공개 반영

확인일: 2026-09-08. 상태: 채택.

제보 하나는 한 업소의 한 메뉴·제공 품목과 사용 용도, 최대 10개 식재료를 다룬다. 식재료 카탈로그와 국가 구성은 기존 원산지 모델을 재사용한다. 원문과 실제 관찰일은 제출자가 입력하며 수집일은 제출본 접수 시각이다. 승인 시각으로 관찰일을 갱신하지 않는다.

수정마다 불변 제출본을 추가한다. 상태·버전 변경은 제보 행 잠금 아래 처리하고 승인·반려·보완 요청·철회 이력을 남긴다. 승인된 기록은 사용자가 수정할 수 없다. 새로운 정정은 별도 기록으로 구현한다. 서버는 인증 주체를 사용하며 타인의 제보는 404로 응답한다.

신규 제출은 사용자별 UUID 요청 키와 본문 해시를 24시간 보관한다. 같은 키를 동시에 보내면 DB 트랜잭션 잠금으로 하나만 생성한다. 다른 본문이면 409다. 브라우저는 응답 실패 때 동일 본문의 키를 보존하고 자동 재전송하지 않는다. 수정·검수의 응답 유실은 최신 상태를 확인한 뒤 처리한다.

공개 동의는 제출본에 버전과 함께 기록한다. 이는 국산김치맵 서비스 내 공개 동의이며 오픈소스 라이선스나 외부 협회 데이터 이용 허가를 대신하지 않는다. 사진 공개는 관리자의 개별 개인정보 검토가 있어야 한다. 미검토 사진·원본은 공개하지 않는다. 공개 엔드포인트는 정제본만 반환한다.

승인 트랜잭션에서 사진 공개 권한, 불변 원산지 기록·국가 구성, 결정적인 공개 판정과 이력을 함께 반영한다. 기존 품목을 선택하면 업소·용도가 일치해야 한다. 이름만으로 자동 병합하지 않는다. 기존 승인 기록과 충돌하면 분쟁으로 남긴다. 한 품목·식재료의 승인 이력이 2천 건을 넘으면 일부만으로 판정하지 않고 전체 승인을 422로 거부한다.

근거는 표시판 관찰이며 협회 지정·실제 납품 검증으로 격상하지 않는다. 공개 텍스트에 제출자의 회원 식별자는 포함하지 않는다. 개인정보가 있는 사진은 관리자가 공개 선택을 하지 않으며, 정제 과정의 EXIF 제거가 얼굴·전화번호 제거를 대신하지 않는다.

남은 범위: 관리자 원산지 정정·지정 관리·업소 매칭 검토, 운영 보관 기간과 삭제 절차, 실제 외부 로그인과 연결된 전체 사용자 흐름 검증. 검수되지 않은 협회 자료는 수집하지 않는다.
