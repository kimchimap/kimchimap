# 현재 김치 입력 범위와 외부 검증 경계

- 결정일: 2026-11-12
- 제품 화면은 배추·고춧가루의 김치 원산지만 선택한다. 식재료 식별자를 지도 필터와 제보 양식에서 공유하고 제보 입력은 두 재료로 제한한다.
- 적용된 원산지·카탈로그 스키마와 불변 감사는 보존한다. 과거 기록을 임의 삭제하거나 김치 근거로 추정하지 않는다. 내부 API의 확장 가능한 모델은 범용 탐색 UI 제공을 뜻하지 않는다.
- 초기 실제 원산지 자료가 없는 상태를 공개한다. 허가가 확인되지 않은 협회 목록·배달앱 자료는 수집하지 않는다. 일반음식점 전체 수집 코드는 제거했다.
- smoke-external은 실제 지도 SDK·타일·공식 로그인 인가 진입까지만 자동 확인한다. 실제 사용자 동의·코드 교환 완료와 데이터 수집을 성공으로 확장하지 않는다.
- 지도 타일 검사는 실제 관찰된 mts.kakaocdn.net과 기존 mts.daumcdn.net의 이미지 HTTP 200을 확인한다. 처음의 구 도메인 전용 검사는 현재 네트워크 응답을 반영해 고쳤으며 검사를 제거하거나 성공 코드로 바꾸지 않았다.
- 완료·대체된 계획은 completed에 이력으로 보관하고 현재 구현 상태는 service-implementation, integrations-status, validation에서 관리한다.
