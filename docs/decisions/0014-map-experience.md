# 지도·목록·상세 연결

확인일: 2026-09-08. 상태: 구현·전체 검증·지도 실연동 확인.

카카오 공식 [시작 가이드](https://apis.map.kakao.com/web/guide/)와 [API 문서](https://apis.map.kakao.com/web/documentation/)에서 비동기 로딩·위경도 인자·이벤트 정리·장소 조회 명세를 확인했다. SDK는 한 Promise로 공유하고 15초 제한·오류 후 요소 정리·명시적 재시도를 적용한다. 지도 객체는 Query 캐시에 넣지 않으며 마커·리스너·ResizeObserver를 정리한다. React 개발 모드의 반복 설정·정리를 테스트한다.

지역 검색은 지도 이동 보조다. 카카오 응답으로 자체 업소·원산지를 만들거나 별도로 저장하지 않는다. 기본 지역은 도시 탐색 시작점이며 업소의 주소를 추정한 좌표가 아니다. 실제 업소 조건·거리·정렬은 서버 PostGIS 검색을 그대로 사용한다. 최대 200개를 표시하고 일부 결과·확대 필요를 안내한다.

검색 필터는 품목별 그룹·식재료 조건으로 구성한다. 같은 그룹의 배추와 고춧가루가 서로 다른 김치를 합쳐 충족하지 않도록 API 구조를 유지한다. 국가 선택의 혼합 포함은 별도 선택이다. 미확인·상충·만료와 지정 사실을 긍정적 국내산으로 표시하지 않는다.

위치와 지도 상태는 메모리에만 둔다. 상세를 같은 화면에 열고 선택 전 지도 중심과 목록 초점을 복원한다. 드래그·확대·지역 선택은 새 검색을 만들지만 시트 크기 변경이나 상세 확인용 중심 이동은 검색을 바꾸지 않는다. 모바일 시트는 지도 영역과 분리해 로고·출처를 가리지 않는다.

테스트의 키 없는 지도는 실제 지도 연동 성공이 아니다. 실제 브라우저에서 SDK·타일 HTTP 200, 지역 검색 결과·서비스 검색, 기존 실수집 업소 13개와 상세 연결을 별도 확인했다. 원산지 자료는 여전히 없으며 실제 카카오 사용자 로그인은 미확인이다.

2026-11-12 후속 결정: 범용 필터 UI는 제거하고 세 김치 필터로 대체한다. 과거 13개 일반 업소 노출은 잘못된 제품 범위였으며 실제 원산지 확보가 아니었다. 기존 수집 자료는 현재 유효 데이터로 사용하지 않는다. 현재 구현·검증은 kimchi-map 계획을 따른다.
