# 연동 및 권한 상태

2026-09-07 조사 기준. 카카오 REST/JavaScript 키·로그인 시크릿·공공데이터 Decoding 키를 Git 제외된 공통 로컬 파일에 권한 600으로 저장했다. 값은 문서·로그에 출력하지 않는다. 저장과 실연동 확인은 별개다.

- 공공 API: 사용자가 일반음식점 조회서비스 활용 승인 완료 확인. 공식 내장 Swagger의 HTTPS /info 명세에 따라 수집기에서 200건을 받아 로컬 DB에 199개 업소를 저장했다. 애매한 매칭 1건은 격리했다. 196개 좌표와 7개 전화번호가 있으며 실제 상세·반경 검색 HTTP 200을 확인했다. 작업 4947bcc0-2d59-41a1-90fe-7eee6dac77f6은 PARTIAL/다음 페이지 3이며 전국 수집 완료가 아니다. 원산지 필드 제공 안 됨.
- 실제 원산지 데이터: 확보하지 않음. 협회 자동 수집/재게시 허가는 사용자가 아직 없다고 확인했다. 이용 허락 확인 대기이며 수집하지 않는다.
- 카카오 지도·로그인: 공식 문서 확인, 키 저장 완료. 사용자가 카카오맵·로그인·OIDC 활성화, localhost:5173 도메인과 고정 callback 등록 완료를 확인했다. 카카오 OAuth 클라이언트·OIDC/PKCE·브라우저 복구를 구현했고 통제된 공급자 테스트를 수행했다. 저장된 앱 키·고정 콜백·openid·PKCE로 공식 인가 진입을 제한 호출하여 HTTP 302/accounts.kakao.com 이동, KOE 오류 없음까지 확인했다. 실제 사용자 동의·코드 교환 완료와 지도 실연동은 아직 미확인.
- PostgreSQL/PostGIS·Redis: 하네스 인프라 실행 결과는 [검증 기록](validation.md) 참조. 앱의 실제 DB/Flyway/Redis 연결 테스트 완료. 업소·원산지 공개 조회와 공간 검색은 실제 DB로 검증 완료. 일반음식점 외부 수집도 확인했으며 서비스 세션과 통제된 OIDC 인증도 검증한다.
- GitHub: origin=https://github.com/kimchimap/kimchimap.git, 공개 저장소, 조회 시 admin 권한 확인. 원격 main/dev 존재. main ruleset 22441352, dev ruleset 22441452 활성 상태와 유효 규칙 조회 확인. classic 보호 대신 ruleset을 사용.
- 사용자 구현 지시에 따라 원격 dev 생성과 main/dev 보호 적용을 완료했다. 하네스 PR #1을 dev에 병합하고 해당 임시 브랜치를 로컬·원격에서 삭제했다. 앱 기반 PR #2와 원산지 모델 PR #3, 공간 검색 PR #4, 실제 수집 PR #5, 서비스 세션 PR #6도 dev 병합과 임시 브랜치 로컬·원격 삭제를 완료했다.
- 라이선스 미선택, 권리자 미확정. 서드파티 이용 조건과 출시 전 개인정보 보유기간 결정 필요.

갱신할 때 구현됨/모의 테스트 통과/실연동 확인/운영 준비를 따로 기록한다. 외부 페이지를 다시 읽은 시점을 실제 자료의 관찰일로 바꾸지 않는다.

2026-09-08 지정·매칭 관리 구현 중에도 협회 수집·저장·재게시 허가는 없음으로 유지한다. 지정 전용 이용 범위는 기본 거부이며 실제 지정·원산지 자료를 새로 수집하지 않았다. 통합 테스트에 사용한 소스·업소·지정은 모두 테스트 DB의 가상 자료다.
