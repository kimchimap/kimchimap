# 연동 및 권한 상태

2026-09-07 조사 기준. 카카오 REST/JavaScript 키·로그인 시크릿·공공데이터 Decoding 키를 Git 제외된 공통 로컬 파일에 권한 600으로 저장했다. 값은 문서·로그에 출력하지 않는다. 저장과 실연동 확인은 별개다.

- 공공 API: 사용자가 일반음식점 조회서비스 활용 승인 완료 확인. 공식 내장 Swagger의 HTTPS /info 명세에 따라 실제 키로 2개 레코드 조회 성공(HTTP 200/resultCode 0). 서비스 DB 저장·공개 조회는 아직 없음. 수집기 구현 전.
- 실제 원산지 데이터: 확보하지 않음. 협회 자동 수집/재게시 허가 미확인.
- 카카오 지도·로그인: 공식 문서 확인, 키 저장 완료. 사용자가 카카오맵·로그인·OIDC 활성화, localhost:5173 도메인과 고정 callback 등록 완료를 확인했다. 실제 지도·로그인 실연동은 아직 미확인.
- PostgreSQL/PostGIS·Redis: 하네스 인프라 실행 결과는 [검증 기록](validation.md) 참조. 앱의 실제 DB/Flyway/Redis 연결 테스트 완료. 업소·원산지 공개 조회와 공간 검색은 실제 DB로 검증 완료. 외부 수집·인증은 미구현.
- GitHub: origin=https://github.com/kimchimap/kimchimap.git, 공개 저장소, 조회 시 admin 권한 확인. 원격 main/dev 존재. main ruleset 22441352, dev ruleset 22441452 활성 상태와 유효 규칙 조회 확인. classic 보호 대신 ruleset을 사용.
- 사용자 구현 지시에 따라 원격 dev 생성과 main/dev 보호 적용을 완료했다. 하네스 PR #1을 dev에 병합하고 해당 임시 브랜치를 로컬·원격에서 삭제했다. 앱 기반 PR #2와 원산지 모델 PR #3도 dev 병합과 임시 브랜치 로컬·원격 삭제를 완료했다.
- 라이선스 미선택, 권리자 미확정. 서드파티 이용 조건과 출시 전 개인정보 보유기간 결정 필요.

갱신할 때 구현됨/모의 테스트 통과/실연동 확인/운영 준비를 따로 기록한다. 외부 페이지를 다시 읽은 시점을 실제 자료의 관찰일로 바꾸지 않는다.
