# 연동 및 권한 상태

2026-09-07 조사 기준. 실제 API 키 값은 읽거나 출력하지 않았다. 사용자는 카카오·공공 API가 아직 준비되지 않았다고 확인했다.

- 공공 API: 설명 페이지 열람만, 실제 호출·저장·공개 조회 없음. 수집기 미구현.
- 실제 원산지 데이터: 확보하지 않음. 협회 자동 수집/재게시 허가 미확인.
- 카카오 지도·로그인: 공식 문서 확인, 앱 설정·키·실연동 미확인.
- PostgreSQL/PostGIS·Redis: 하네스 인프라 실행 결과는 [검증 기록](validation.md) 참조. 앱의 실제 DB/Flyway/Redis 연결 테스트 완료. 도메인 수집·인증은 미구현.
- GitHub: origin=https://github.com/kimchimap/kimchimap.git, 공개 저장소, 조회 시 admin 권한 확인. 원격 main/dev 존재. main ruleset 22441352, dev ruleset 22441452 활성 상태와 유효 규칙 조회 확인. classic 보호 대신 ruleset을 사용.
- 사용자 구현 지시에 따라 원격 dev 생성과 main/dev 보호 적용을 완료했다. 하네스 PR #1을 dev에 병합하고 해당 임시 브랜치를 로컬·원격에서 삭제했다. 앱 기반 PR을 준비한다.
- 라이선스 미선택, 권리자 미확정. 서드파티 이용 조건과 출시 전 개인정보 보유기간 결정 필요.

갱신할 때 구현됨/모의 테스트 통과/실연동 확인/운영 준비를 따로 기록한다. 외부 페이지를 다시 읽은 시점을 실제 자료의 관찰일로 바꾸지 않는다.
