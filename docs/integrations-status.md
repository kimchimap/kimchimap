# 연동·권한·실제 데이터 상태

확인일: 2026-11-12. 구현, 자동 검증, 외부 실연동, 운영 준비를 구분한다.

| 대상 | 현재 상태 | 확인 범위·한계 |
| --- | --- | --- |
| PostgreSQL/PostGIS·Redis | 실제 연결·자동 검증 | 로컬 인프라, 빈 DB Flyway, 실제 컨테이너 통합·공간 실행계획 |

| 카카오 로그인 | 실제 사용자 로그인 완료 확인 | 사용자 지도 복귀·계정 관리 표시 확인, 로컬 활성 회원 1명·Redis 활성 세션 1개 확인. 실제 외부 로그아웃·탈퇴는 별도 미검증 |

| 일반음식점 API | 원산지 필드 없음·제거됨 | 전체 업소 수집에 부적합. 호출부·파서·키 전달 제거, 과거 부적합 로컬 업소 199건 삭제 |
| 다른 지자체·외식업 자료 | 적합한 초기 소스 미확보 | 개별 목록의 이용 조건과 지정/원재료 범위 확인 필요 |
| GitHub | main/dev ruleset 적용 | PR 필수·강제 push/삭제 금지, 로컬 자연어·head 규칙 강제 한계는 Git 문서 참조 |
| 운영 배포·라이선스 | 미실행·미선택 | 출시 전 별도 결정 |

**현재 로컬 실제 업소와 원산지 데이터는 0건이다.** 공개 조건에 맞는 데이터가 없으면 빈 목록을 표시한다. 임시 통합 테스트의 가상 업소와 사진은 실제 초기 자료가 아니며 로컬 서비스에 주입하지 않는다.

외부 키는 Git 제외된 권한 600의 `.local/integrations.env`에서 읽는다. 카카오 앱 지도·로그인, localhost:5173 도메인과 고정 callback 등록은 사용자가 완료했다고 확인했다. 실제 로그인에서 KOE205가 발생해 콘솔을 확인하니 OIDC는 OFF였다. 2026-11-12 사용자의 명시적 승인 후 기존 앱의 OpenID Connect만 ON으로 변경했고 저장 성공을 확인했다. 프로젝트·키·다른 설정은 변경하지 않았다. 공공데이터 키는 보존하되 더 이상 실행 환경에 전달하지 않는다.

`./scripts/harness smoke-external`은 실제 SDK·지도 타일·공식 인가 진입을 재현한다. 2026-11-12에는 dapi.kakao.com, t1.kakaocdn.net, mts.kakaocdn.net의 응답을 확인했다. 초기 검사기가 과거 daumcdn 타일 도메인만 확인하여 실패한 뒤 실제 타일 CDN 기준으로 수정했고 PC/모바일 2건이 통과했다. 공식 인가 진입은 PKCE S256·openid를 포함하고 accounts.kakao.com 이동까지 확인했다. 사용자 로그인은 자동으로 수행하지 않았다.

과거 호출·삭제·PR 결과는 [검증 기록](validation.md), 소스별 조건과 확인 주소는 [소스 조사](data-sources.md)에 보존한다. 원천 페이지를 다시 읽은 시각을 관찰일이나 인증일로 바꾸지 않는다.

2026-11-12 수동 실연동: 사용자가 실제 카카오 로그인 후 지도 복귀와 계정 관리 표시를 확인했다. 로컬 DB의 활성 회원 수 1명과 Redis 활성 세션 수 1개를 집계해 서비스 세션 생성도 확인했다. 토큰·공급자 식별자·프로필은 기록하지 않았다. 이 결과는 위 자동 smoke와 별개이며 실사용 로그아웃·탈퇴나 운영 배포 검증까지 포함하지 않는다.
