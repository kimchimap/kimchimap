# 데이터 소스 조사 장부

확인일 2026-09-07. 페이지 열람과 API 실연동은 다르다. 모든 수집기는 아직 미구현이며 실제 원산지 데이터는 없다. 아래 공식 문서만 조사했고 자료를 대량 수집·커밋하지 않았다.

| 소스·기관·공식 URL | 확인 범위 | 조건·미확인 사항 | 연동 상태 |
| --- | --- | --- | --- |

공통 알려진 품질 한계: 인허가 행정 변경과 실제 영업 사이 시차, 누락/불량 좌표, 지점 명칭 불일치 가능. 구체 오류율과 시차는 측정 전 수치화하지 않는다. 지정 제도 사실을 모든 부재료의 원산지로 확장하지 않는다. 카카오 장소에서 원산지를 추정하지 않는다.

소스 추가 시 필수 항목: 제공기관, 공식 URL, 실제 조회 방식과 명세, 제공 필드, 키 필요, 호출 제한(단위 포함), 원천 주기, 자동 수집 허용, 저장·재게시·재배포와 출처 표시, 조건 확인일, 누락·오류·시차, 구현/실연동 상태, 허용 fixture 근거. unknown은 unknown으로 남기고 수집을 켜지 않는다.

상태 어휘: 실제 호출과 저장까지 확인됨 / 클라이언트 구현됨, 인증키 미설정 / 이용 허락 확인 대기 / 원산지 필드 제공 안 됨 / 외부 장애로 검증 미완료 / 아직 미구현. 복수 상태를 병기할 수 있다.
