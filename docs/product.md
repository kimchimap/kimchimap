# 제품 범위와 완료 단계

서비스명은 국산김치맵, 저장소명은 kimchimap이다. 주변 음식점을 지도·목록에서 식재료 원산지 조합으로 찾고 적용 메뉴·용도·출처·관찰 날짜·최신성·분쟁을 확인한다. 로그인 사용자는 즐겨찾기와 사진 제보, 관리자는 검수·정정·매칭·수집 재실행을 수행한다.

초기 요청은 하네스 구성이었고 완료했다. 추가 사용자 지시에 따라 **작업 단위별 서비스 구현·검증·dev PR 병합**을 진행한다. 아래 기능은 후속 구현의 필수 범위이며 후속 기능을 현재 동작한다고 표시하지 않는다. 현재 사용자 추가 지시로 작업 단위 구현을 시작했다.

포함: Spring MVC 단일 서버, React 모바일 우선 웹, PostgreSQL/PostGIS, Redis 상태 보유 인증, 카카오 지도·로그인, 지도/반경 검색, 식재료·국가·근거·신선도 필터, 상세/즐겨찾기/내 제보/검수/수집 화면, 파일 검증, 허용된 외부 수집기, 자동 검증·문서·기여 도구.
제외: 운영 구축·배포, CI/CD·Actions, 업주 역할, 자체 비밀번호 회원가입, 결제·광고·평점·일반 리뷰, 네이티브 앱·다국어, 필요 없는 분산 서비스·Kafka·Kubernetes·유료 AI.

| 단계 | 완료 증거 | 현재 |
| --- | --- | --- |
| 하네스 | 도구 실행과 성공·실패 자동 테스트 | 검증 기록 참조 |
| 서비스 구현 | 실제 frontend/backend 기능과 저장소 | 업소·원산지·공간 검색·일반음식점 수집, 연락처 화면 구현 |
| 자동 테스트 | 단위·실제 DB/Redis·계약·E2E 결과 | 앱 기반 검증 실행, 업소·원산지 도메인 단위/DB 검증 통과, 수집 계약·DB 테스트 통과, 인증·제보 등 후속 검증 미구현 |
| 외부 실연동 | 허용된 실제 수집→저장→공개 조회·카카오 실증 | 일반음식점 제한 범위 확인, 카카오 미확인 |
| 운영 준비 | 라이선스·데이터 권리·보안·관리절차 점검 | 미완료·배포 범위 밖 |

오픈소스 라이선스는 미선택이다. 이미 공개 저장소라는 사실이 재사용 라이선스를 대신하지 않는다. 권리자와 MIT/Apache-2.0 등을 임의 확정하지 않는다. 서드파티 코드·데이터·이미지 조건은 별도 장부로 관리한다.

## 업소 연락처

사용자가 업소에 문의할 수 있도록 공식 데이터에 공개된 업소 전화번호를 제공한다. 원문 표시 번호와 전화 연결용 정규화 번호, 출처를 구분하여 저장한다. 상세 화면에는 번호·출처와 `전화 걸기` 링크를 제공하며, 모바일에서는 전화 앱에 연결한다. 번호가 없거나 허용한 형식을 충족하지 않으면 번호 없음으로 안내하고 연결 링크를 만들지 않는다. 실제 통화 가능 여부를 확인했다고 표시하지 않는다. 대표자 개인 연락처를 별도로 찾지 않는다.
