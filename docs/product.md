# 국산김치맵 제품 계약

2026-11-12 확정. 대한민국 전국에서 국내산 배추 또는 고춧가루를 사용하는 김치 제공 음식점을 찾는 모바일 우선 지도 서비스다. 이 문서가 이전의 범용 식재료 탐색 기획보다 우선한다.

## 검색과 상세

지도 필터는 **국산 배추**, **국산 고춧가루**, **둘 다 국산**이다. 둘 다 조건은 동일한 김치 품목·사용 용도의 근거에서 충족해야 한다. 반찬 김치와 찌개 김치 정보를 합치지 않는다. 혼합·미확인·만료·분쟁은 순수 국내산 조건에 포함하지 않는다. 전국을 지원하되 넓은 지도에는 확대 안내나 집계 표시를 사용한다.

상세는 해당 김치 품목·용도, 출처, 근거, 인증 날짜, 주소와 공개된 업소 전화번호, 좋아요 수를 표시한다. 제보 인증 날짜는 관리자가 승인한 시각이며 ‘국산김치맵 제보 승인’으로 표시한다. 자율표시제 자료는 ‘자율표시제 지정일’로 구분한다. 외부 날짜가 없으면 ‘지정일 미제공’으로 표시하며 수집일을 인증일로 사용하지 않는다. 식재료 실물 납품·위생·안전 인증으로 설명하지 않는다.

## 등록과 변경

사용자가 지도 위치를 선택하고 ‘제보하기’를 누르면 업소명·주소·김치 용도·원산지 표시판 사진·관찰일을 제출한다. 관리자 승인 전에는 지도에 등록하지 않는다. 관리자가 위치·업소 일치·사진·원산지를 확인하고 승인하면 업소 등록과 공개 근거·승인일을 한 트랜잭션으로 반영한다.

다른 사용자는 기존 정보의 오류를 신고할 수 있다. 신고는 등록 제보와 구분하고 원산지 변경·폐업·위치 오류 등 사유와 증빙을 받는다. 관리자는 보완 요청·기각·정정 처리를 수행하고 이유·처리자·시간을 남긴다. 신고 접수만으로 공개 기록을 자동 덮어쓰거나 삭제하지 않는다.

## 좋아요

로그인 사용자는 업소당 좋아요 하나를 등록·취소한다. 공개 상세에 합계, 개인 화면에 ‘내가 좋아요한 가게’를 제공한다. 기존 즐겨찾기는 이 기능으로 통합한다. 내 목록과 사용자 신원은 비공개다.

## 초기 데이터와 제외 범위

초기 데이터 소스는 국산김치 자율표시제다. 수집·저장·재게시 이용 조건을 확인한 범위만 가져온다. 지정 기준과 적용 김치를 보존하고 95% 국산 예외를 두 재료 모두 국내산으로 확대하지 않는다. 일반음식점 API의 전체 업소 선행 수집은 제거한다. 배달의민족·쿠팡이츠 크롤링은 추후 허용 여부·필드·접근 조건을 조사한 뒤 결정한다.

범용 식재료 탐색 UI, 별도 즐겨찾기, 일반 리뷰·평점, 배달 주문, 광고·결제, 업주 계정은 현재 범위에서 제외한다. 인증·파일 검증·감사·수집 실패 복구·검증 하네스는 유지한다. CI/CD·운영 배포는 수행하지 않는다. 오픈소스 라이선스는 아직 미선택이다.

현재 구현 여부와 실제 검증은 작업 계획·검증 기록에서 별도 관리한다. 이 계약은 완료 보고가 아니다.
