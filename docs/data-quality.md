# 원산지 판정과 검색

판정 키는 restaurant + serving_scope + ingredient다. serving_scope는 동일 김치 품목과 사용 용도를 식별한다. 반찬 배추김치의 배추와 찌개 김치의 고춧가루를 합쳐 매칭하지 않는다. 메뉴 한 개만 조건에 맞으면 matchedScopes에 그 메뉴를 반환하며 업소 전체로 일반화하지 않는다.

결정 절차(동일 입력·asOf에서 동일 결과):
1. 승인되지 않은 기록, 효력 전/후, 철회/취소 기록은 긍정 매칭 후보에서 제외한다.
2. 명시적인 관리자 해결 revision은 대상 충돌 기록을 참조해야 한다. 새 상충 기록이 들어오면 해결 범위 밖의 충돌은 다시 검토한다.
3. 같은 키에 현재 유효한 서로 다른 원산지 주장이 있으면 DISPUTED로 남기고 긍정 검색에서 제외한다. 관찰일 미상 기록도 일치 여부를 임의 추정하지 않는다.
4. 충돌 없는 동일 주장은 실제 관찰일 DESC NULLS LAST, 원문 갱신일 DESC NULLS LAST, review revision, id로 대표 표시 기록을 결정한다. 수집일은 확인일 우선순위에 쓰지 않는다.
5. 새 다운로드는 last_fetch_succeeded_at만 바꾸고 관찰일을 갱신하지 않는다. 동일 내용은 revision을 남발하지 않는다. publication에는 정책 버전과 선택 이유를 남긴다.

다른 식재료는 AND, 같은 조건의 복수 국가는 OR. 기본 국가 매칭은 기록이 단일 원산지일 때만 허용한다. 혼합은 별도 includeMixed를 명시할 때 구성 국가와 매칭하며 순수 국내산 필터와 함께 사용할 수 없다. UNKNOWN, DISPUTED, EXPIRED는 국내산 조건을 충족하지 않는다. 국가 미표기 수입과 미확인은 별도 필터다.

최신성 기본 표시 기준은 관찰일 180일 경과 시 오래됨(제품 기본값, 법적 유효기간 아님). 관찰일 미상은 확인일 미상. 명시 valid_until은 우선 적용한다. 날짜 없는 데이터를 최신 필터로 통과시키지 않는다. 조건 없는 공개 조회에서는 오래됨·분쟁 안내를 보여줄 수 있다.

매칭은 안정적 공공 ID/외부 ID 우선, 주소·이름·좌표는 후보 선정에만 사용한다. 이름만 병합 금지, 프랜차이즈 지점 분리, 모호하면 관리자 검토. 한 페이지 누락·한 번 실패는 폐업/지정 취소가 아니다. 완료된 전체 대조에서도 누락 상태를 먼저 기록하고 명시 취소 또는 검토 후 상태 변경한다.

사용자 안내: 표시판 내용 확인은 실제 납품 인증이 아니며 원산지는 위생·안전성 인증을 뜻하지 않는다. 정보 없음은 수입산을 뜻하지 않는다.

관리자 정정은 명시한 잘못된 기록만 철회하고 나머지 근거로 기존 결정적 판정을 다시 적용한다. 전부 철회하면 UNAVAILABLE이다. 이후 새 상충 기록은 기존 정정 범위에 포함하지 않고 다시 분쟁 판정한다. 새 원산지 내용은 제보·검수로 별도 기록을 추가한다. [결정 기록](decisions/0012-origin-corrections.md)을 참조한다.

지정 공개는 일반 수집·재게시 허가 외에 지정 정보 이용 범위 허가도 요구한다. 공개 허가 철회 시 기존 지정은 공개 응답에서 제외된다. 애매한 매칭은 당시 관찰본과 지점 주소·좌표를 비교하여 관리자 결정으로만 연결한다. 동일 출처의 서로 다른 식별자를 같은 업소에 연결하지 않는다. 결정 시각을 원천 갱신일·마지막 수집 성공일로 바꾸지 않는다.
