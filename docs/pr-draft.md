## 변경 목적

로그인 이후 서비스 토큰과 세션을 안전하게 갱신·폐기하고, 현재 회원 상태와 권한을 모든 보호 API에서 확인하도록 구현했습니다. 카카오 로그인 연결은 다음 작업으로 분리했습니다.

## 주요 변경 사항

JWT 발급·서명·필수 클레임 검증, Redis의 원자적인 토큰 회전·발급 이력·재사용 탐지·세션 상한을 구현했습니다. 갱신·로그아웃·전체 로그아웃·회원 조회·탈퇴 API와 CSRF·출처 검증·쿠키 정책을 연결했습니다. 회원 권한·상태 변경 이력을 남기고 이전 토큰을 거부합니다.

## 검증 방법과 실제 결과

전체 `verify`를 통과했습니다. 실제 DB·Redis로 동시 갱신·재사용·폐기·정지·권한 변경·장애·쿠키·CSRF를 검증했습니다. 서명 위조·만료·잘못된 발급자와 대상·알고리즘 혼동·운영 키 누락 거부를 확인했고 기존 검색·수집·브라우저·빌드 검사도 통과했습니다.

## 데이터·보안 영향

갱신 토큰 원문은 Redis에 저장하지 않습니다. 알 수 없는 토큰으로 다른 세션을 폐기하지 않으며 Redis 장애에서 보호 API를 허용하지 않습니다. 공개 조회는 가능한 범위에서 유지합니다. 로그인 우회 API나 기본 관리자 계정은 만들지 않았습니다.

## 호환성·마이그레이션

다섯 번째 마이그레이션으로 회원과 보안 변경 이력을 추가했습니다. 운영은 외부 서명키가 필수이고 로컬 메모리 키의 재시작·교체 동작을 문서화했습니다. API 계약과 생성 타입을 갱신했습니다.

## 남은 사항

카카오 OAuth 연결과 브라우저 로그인·갱신 처리는 다음 작업입니다. 이번 합성 회원 테스트는 실제 카카오 로그인 성공을 의미하지 않습니다. 관리자 지정 절차와 전체 화면 연결도 이어서 구현합니다.
