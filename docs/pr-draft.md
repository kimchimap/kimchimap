## 변경 목적

주변 음식점을 실제 DB 공간 검색으로 찾고 메뉴·용도가 같은 원산지 조건만 결합하도록 구현했습니다. 지도 영역과 미터 반경 검색의 필터 의미를 맞췄습니다.

## 주요 변경 사항

공개 검색 API, 식재료 그룹과 국가 선택, 서명된 페이지 이동, 실제 좌표 변환, 검색 요청 제한을 구현했습니다. 비공개 승인 기록의 충돌도 판정에 반영하며, 혼합·미확인·만료 정보를 순수 국내산으로 처리하지 않습니다.

## 검증 방법과 실제 결과

`verify-unit spatial-search`를 통과했습니다. 단위와 계층 검사 18개, 실제 DB와 Redis 통합 23개, 가상 업소와 원산지 각 2만 건 성능 검사 1개가 성공했습니다. 하네스 28개, 프론트 2개, 모바일 및 PC E2E 2개, API 타입 일치와 양쪽 빌드도 확인했습니다.

## 데이터·보안 영향

공간 검색은 바인딩 SQL과 입력 상한을 사용합니다. 읽기 전용 검색 요청만 CSRF 예외이며 인증 경로 보호는 유지합니다. Redis 장애 때 공개 검색은 제한된 메모리 방식으로 유지됩니다. 키는 Git 제외된 로컬 파일에만 있습니다.

## 호환성·마이그레이션

기존 마이그레이션을 보존하고 검색용 인덱스를 추가했습니다. 운영 검색 페이지 서명키가 없으면 시작을 거부합니다. 페이지 사이 데이터 변경과 측정 환경의 한계를 문서화했습니다.

## 남은 사항

카카오 설정과 공공 API 활용 승인을 확인했고, 공공 API의 제한된 실제 조회도 성공했습니다. 수집기 저장·조회와 지도 화면·인증·제보는 다음 작업입니다. 실제 원산지 자료는 아직 없습니다.
