## 변경 목적

하네스에서 지정한 명령으로 실제 서버와 화면을 실행하고 검증할 수 있도록 애플리케이션 기반을 구현했습니다.

## 주요 변경 사항

Spring MVC 서버와 한국어 상태 화면, 실제 PostGIS 및 Redis 연결, Flyway 초기화, 안전한 기본 접근 거부와 요청 추적을 구성했습니다. OpenAPI에서 프론트 타입을 생성하고 변경을 검사합니다. 공식 런타임과 Gradle Wrapper를 고정하고 작업 단위 검증을 추가했습니다.

## 검증 방법과 실제 결과

`./scripts/harness verify-unit application-foundation`을 통과했습니다. 하네스 회귀, 백엔드 단위와 실제 DB 및 Redis 통합, UI 테스트, 모바일과 PC E2E, 양쪽 빌드, API 타입 일치를 확인했습니다. 상세 결과는 `docs/validation.md`에 기록했습니다.

## 데이터·보안 영향

외부 업소와 원산지 자료는 아직 없습니다. 미구현 보호 경로는 거부하며 기본 사용자 자동 생성을 차단했습니다. 로컬 설정은 실행하지 않고 허용된 키만 읽습니다. 실제 비밀값을 커밋하지 않았습니다.

## 호환성·마이그레이션

`V1__initialize_application_schema.sql`은 PostGIS 확장을 확인합니다. 도메인 테이블은 다음 작업에서 추가합니다. 기존 볼륨과 시스템 런타임을 보존합니다. TypeScript는 API 생성 도구와 공통 지원 범위에 맞췄습니다.

## 남은 사항

업소와 원산지 모델, 공간 검색, 수집, 로그인과 제보 도메인을 다음 작업에서 구현합니다. 카카오와 공공 API 설정은 사용자가 준비 중입니다. 전체 서비스 완료와 운영 배포는 아닙니다.
