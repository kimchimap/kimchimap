## 변경 목적
사용자가 표시판 원산지를 제보하고 관리자가 검수한 내용을 공개 원산지 정보에 반영할 수 있게 합니다.

## 주요 변경 사항
본인 제보 작성·수정·철회와 관리자 승인·반려·보완 요청의 API와 화면을 구현했습니다. 불변 제출본·동의·검수 이력과 중복 요청 처리를 추가했습니다. 승인과 원산지 공개 판정, 개인정보 검토된 사진 공개를 같은 트랜잭션으로 반영합니다. 기존 원산지와 상충하면 분쟁 상태를 유지합니다.

## 검증 방법과 실제 결과
최종 전체 검증을 통과했습니다. 단위·계층 33건, 실제 PostGIS·Redis 통합 55건, 외부 계약 5건, 성능 1건, 프론트 27건, 모바일·PC 브라우저 12건, 하네스 28건이 통과했습니다. 최초 포맷·DB 연결 시간 초과·합성 인증 응답 누락을 수정한 뒤 전체를 다시 검증했습니다. 실제 앱 계정 SQL 접속을 확인한 뒤 통합 테스트를 시작하도록 준비 조건을 강화했습니다.

## 데이터·보안 영향
작성자 소유권과 관리자 권한, 버전 충돌을 서버에서 검사합니다. 승인된 제출본을 사용자가 수정할 수 없습니다. 사진은 개별 개인정보 검토를 마친 정제본만 공개하며 원본은 비공개입니다. 제보 승인을 실제 납품 검증으로 표시하지 않습니다. 협회 자동 수집·재게시 허가는 아직 없어 수집하지 않습니다.

## 호환성·마이그레이션
일곱 번째 마이그레이션으로 제보·불변 제출본·검수·요청 키 테이블을 추가합니다. 기존 마이그레이션과 데이터는 유지합니다. 생성 OpenAPI와 프론트 타입을 함께 갱신했습니다.

## 남은 사항
관리자 원산지 정정·지정·업소 매칭·수집 상태 화면과 지도 검색 화면을 이어서 구현합니다. 실제 카카오 계정 로그인 완료와 지도 외부 연동, 운영 보관 정책·라이선스 결정은 별도로 남아 있습니다.

## 관련 이슈
별도 등록된 이슈는 없습니다. 작업 계획과 설계 결정·검증 기록을 갱신했습니다.
