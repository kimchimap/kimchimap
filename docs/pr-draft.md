## 변경 목적
확정된 김치 서비스 범위에 맞춰 입력과 현재 문서를 정리하고 실제 외부 연동 확인 명령을 제공합니다.

## 주요 변경 사항
제보 양식은 배추·고춧가루만 선택하며 지도와 식별자를 공유합니다. 실제 지도 SDK·타일·공식 로그인 인가 진입을 PC·모바일에서 확인하는 별도 명령을 추가했습니다. 완료 계획을 이력으로 옮기고 폐기된 수집·화면 설명과 요구사항 상태를 갱신했습니다.

## 검증 방법과 실제 결과
외부 확인 2건이 통과했습니다. 첫 검사에서 과거 타일 주소만 확인해 실패한 뒤 실제 응답의 현재 주소를 반영했습니다. 전체 기능 검사와 하네스 31건은 통과했으며 화면 테스트의 타입 옵션 오류를 수정하고 타입·빌드를 재확인했습니다. 최종 PR 준비도 전체 통과했습니다. 단위 37·통합 83·내부 계약 7·성능 1·프론트 65·화면 브라우저 24·실제 연결 2·하네스 31건이며 실패와 건너뛰기가 없습니다.

## 데이터·보안 영향
현재 실제 업소·원산지는 각각 0건입니다. 허가 없는 자료는 수집하지 않았고 일반음식점 키·호출부는 사용하지 않습니다. 외부 확인은 키 값·전체 외부 URL·요청·응답 원문을 저장하지 않습니다. 운영용 인증 우회는 없습니다.

## 호환성·마이그레이션
새 DB 스키마 변경 없이 기존 마이그레이션을 보존합니다. 적용된 확장 가능 카탈로그·감사는 유지하고 제품 입력 범위만 김치 두 재료로 제한합니다.

## 남은 사항
허용된 초기 원산지 자료와 실사용 수집기가 없습니다. 실제 카카오 사용자 동의·코드 교환은 미확인이며 라이선스·개인정보 보유기간·운영 준비는 출시 전 별도 사항입니다. 배포·CI/CD는 수행하지 않습니다.

## 관련 이슈
이용 가능한 자료만 사용하고 불필요한 기존 코드·설명을 정리하라는 확정 요구를 반영합니다.
