## 변경 목적
화면 API 모의 응답만으로 놓칠 수 있는 로그인·제보·검수 연결을 실제 서버와 임시 저장소로 검증합니다.

## 주요 변경 사항
테스트 전용 OIDC 공급자와 실제 PostGIS·Redis·사진 저장소에서 PC·모바일 로그인, 사진 제출, 관리자 승인, 지도 세 필터, 좋아요, 오류 신고를 실행합니다. 전체 검증에 연결 브라우저 검사를 추가했습니다. 검증에서 발견한 로그아웃 후 남은 요청의 재갱신 경합을 차단하고 서버 로그아웃 중 새 로그인 진입을 막았습니다.

## 검증 방법과 실제 결과
첫 연결 검증에서 PC는 통과했고 모바일 계정 전환에서 실패했습니다. 로그아웃 완료를 기다리는 화면과 세션 경계를 수정하고 두 화면별 임시 저장소를 분리한 뒤 모두 통과했습니다. 프론트엔드 65건 통과. 승인 전후 사진 공개 접근 검사도 통과했습니다. 전체 검증은 단위 37·통합 83·내부 계약 7·성능 1·프론트 65·화면 브라우저 24·실제 연결 2·하네스 29건 통과했습니다.

## 데이터·보안 영향
테스트 공급자와 관리자 초기화는 테스트 클래스 경로에만 있습니다. 운영 인증 우회 경로는 추가하지 않습니다. 실제 사용자의 키·계정·제보를 사용하지 않고 합성 자료만 임시 저장소에 보관합니다. 보안 요청 제한은 완화하지 않았습니다.

## 호환성·마이그레이션
기존 화면 모의 테스트를 유지하고 실제 연결 검증을 추가합니다. DB 스키마 변경은 없습니다. 테스트 실행에는 비어 있는 로컬 포트와 Docker가 필요합니다.

## 남은 사항
통제된 공급자 확인은 실제 카카오 사용자 동의·외부 지도 연동 확인을 뜻하지 않습니다. 허용된 초기 원산지 자료는 아직 확보하지 않았습니다.

## 관련 이슈
최종 서비스 동작을 화면부터 저장·검수·공개까지 검증해야 한다는 요구를 반영합니다.
