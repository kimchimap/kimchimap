## 변경 목적

허용된 일반음식점 공공 API에서 업소를 수집하고, 검증된 업소 연락처를 사용자에게 제공하도록 구현했습니다. 업소 기본정보를 원산지 근거로 해석하지 않습니다.

## 주요 변경 사항

공식 응답 클라이언트, 증분·전체 대조 작업, 페이지 재개, 원천 식별자와 변경 감지, 좌표 변환, 관리자 정정 보존, 애매한 매칭 검토를 연결했습니다. 실행 임대와 진행 위치·페이지 쓰기를 DB에서 관리하고 재시도·격리·오류 이력을 남깁니다. 전화번호 출처·공개 권한과 전화 걸기 화면을 추가했습니다.

## 검증 방법과 실제 결과

전체 `verify` 통과. 하네스 28개, 백엔드 20개, 실제 DB·Redis 통합 32개, 외부 계약 5개, 성능 1개, 프론트 9개, 모바일·PC E2E 2개와 API 계약·타입·빌드 성공을 확인했습니다. 실제 수집은 200건 중 199개 저장·1개 매칭 검토이며 공개 상세·반경 검색을 확인했습니다.

## 데이터·보안 영향

허용된 고정 HTTPS 주소만 호출하고 인증키·응답 원문을 로그나 저장소에 노출하지 않습니다. 실행 임대 상실 시 쓰기를 거부하며 429 지연과 제한 재시도를 적용했습니다. 출처 공개 허용이 철회되면 연락처를 숨깁니다. 명시적 상태 변경 없이 업소를 폐업 처리하지 않습니다.

## 호환성·마이그레이션

기존 마이그레이션을 보존하고 V4로 수집 추적과 전화번호를 추가했습니다. 상세 계약에 선택적 연락처가 추가되며 OpenAPI 타입을 재생성했습니다. 로컬 데이터 볼륨과 비밀 설정을 보존합니다.

## 남은 사항

실수집은 부분 범위이며 전국 완료가 아닙니다. 실제 원산지 자료는 없으며 협회 자동 수집 허가는 미확인입니다. 인증·관리자 수집 화면·전체 지도 화면·카카오 실연동은 후속 작업입니다. 자동 예약은 기본 비활성입니다.
