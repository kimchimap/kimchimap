## 변경 목적

후속 개발이 저장소 지침과 실행 하네스만으로 이어지도록 초기 개발 기반과 원격 dev 보호를 구성했습니다. 이번 범위는 하네스이며 서비스는 아직 구현하지 않았습니다.

## 주요 변경 사항

계층별 개발 지침, 원산지 모델과 검색 의미, 보안과 수집 설계, 단계별 수용 기준을 기록했습니다. 환경 진단과 로컬 인프라, 한국어 Git 훅과 PR 검사, 보호 설정 계획과 브랜치 정리 도구를 추가했습니다.

## 검증 방법과 실제 결과

`./scripts/harness verify-harness` 회귀 검증을 통과했습니다. 실제 로컬 DB 확장과 역할 제한, Redis 인증 허용과 거부를 확인했습니다. 전체 서비스 검증은 미구현으로 실패하며 상세 결과는 `docs/validation.md`에 기록했습니다.

## 데이터·보안 영향

실제 업소나 원산지 자료를 수집하지 않았습니다. 비밀값은 저장소 밖의 로컬 무시 경로에 생성하고 사용자 설정을 보존합니다. GitHub main/dev 보호를 적용하고 재조회했습니다.

## 호환성·마이그레이션

서비스 마이그레이션은 없습니다. 선택한 PostGIS 컨테이너는 AMD64 이미지이며 Apple Silicon에서 에뮬레이션을 사용합니다. PostGIS 자체는 ARM64에서 사용할 수 있습니다. 인프라 종료 시 볼륨을 보존합니다.

## 남은 사항

서비스 구현, 외부 키와 데이터 이용 조건, 라이선스 선택이 남았습니다. 운영 배포와 자동 병합은 범위에 포함하지 않습니다.

## 관련 이슈

해당 없음. 사용자 요구사항은 `docs/requirements.md`와 후속 계획에 연결했습니다.
