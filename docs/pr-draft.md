## 변경 목적
관리자가 동일 메뉴·용도·식재료의 상충 원산지를 검토하고 잘못된 기록을 제외하여 공개 정보를 정정할 수 있게 합니다.

## 주요 변경 사항
관리자 원산지 목록·상세·정정 API와 화면을 구현했습니다. 명시한 기록의 철회와 불변 감사·공개 재판정을 같은 트랜잭션에서 처리합니다. 기존 원문과 국가 구성은 보존하고 새 상충 정보는 다시 검토합니다. 제보·수집·정정 화면의 회원 접근 경계를 공통화했습니다. 검색의 혼합 옵션 생략 기본값도 바로잡았습니다.

## 검증 방법과 실제 결과
전체 검증을 통과했습니다. 단위·계층 37건, 실제 PostGIS·Redis 통합 61건, 외부 계약 5건, 성능 1건, 프론트 32건, 모바일·PC 브라우저 12건, 하네스 28건이 통과했습니다. 실제 HTTP 검색에서 정정 후 국내산 매칭과 새 상충 기록 후 재제외를 검증했습니다. 초기 검색 요청 기본값 문제를 수정한 뒤 재검증했습니다.

## 데이터·보안 영향
관리자 권한·현재 버전과 같은 원산지 그룹의 대상 기록을 서버에서 확인합니다. 타 품목 철회와 이전 버전 변경은 거부합니다. 원문을 덮어쓰지 않으며 실제 납품 검증으로 안내하지 않습니다. 새 값·증빙은 기존 제보·검수 흐름으로 추가합니다.

## 호환성·마이그레이션
아홉 번째 마이그레이션으로 불변 정정 감사를 추가합니다. 기존 마이그레이션은 수정하지 않았습니다. 생성 OpenAPI·프론트 타입을 갱신했으며 생략 가능한 혼합 옵션은 문서대로 기본 제외 처리합니다.

## 남은 사항
지정 이력·업소 매칭 검토와 지도 전체 화면을 이어서 구현합니다. 협회 이용 허가가 없고 실제 원산지 데이터도 아직 없습니다. 실제 카카오 로그인·지도 전체 연결, 운영 보관 정책과 라이선스 결정은 별도로 남아 있습니다.

## 관련 이슈
별도 등록된 이슈는 없습니다. 계획·설계 결정·검증 문서를 갱신했습니다.
