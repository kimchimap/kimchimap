## 변경 목적
서비스 범위에서 제외한 원산지 없는 일반음식점 자료를 로컬과 이후 마이그레이션에서 제거합니다.

## 주요 변경 사항
해당 외부 소스만 연결된 미사용 업소·원천 좌표와 전화번호·외부 식별자·연결 품질 오류·미검토 자동 후보를 제거합니다. 좋아요·제보·품목·근거·지정·정정·검토·감사·다른 소스가 연결되면 보존합니다. 현재 기능과 데이터 상태에 맞춰 README와 연동 문서를 갱신했습니다.

## 검증 방법과 실제 결과
실제 PostGIS에서 마이그레이션 삭제와 보존 경계를 검증했습니다. 임시 테이블 권한 실패를 권한 확대 없이 단일 SQL 방식으로 수정했습니다. 전체 서비스 검사 통과 후 남은 포맷 오류도 수정했습니다. 로컬 적용 전 업소·원천·외부 식별자 각각 199건에서 적용 후 0건이 됐으며 연결 오류와 미검토 후보도 0건입니다. 최종 준비에서 전체 검사를 재실행합니다.

## 데이터·보안 영향
사용자가 요청한 불필요한 과거 자료 제거입니다. 이용자·검수 기록이 연결된 업소는 보존하고 불변 실행 감사와 집계는 삭제하지 않습니다. Git 제외된 과거 원천 응답 확인 파일을 제거했으며 비밀 설정은 유지합니다. 허가 미확인 자료를 새로 수집하지 않습니다.

## 호환성·마이그레이션
열일곱 번째 마이그레이션은 지정한 폐기 소스의 미사용 자료를 영구 삭제합니다. 기존 Flyway 파일을 변경하지 않습니다. 다른 참조가 존재하면 보존하거나 외래 키 검증으로 실패하며 무조건 연쇄 삭제하지 않습니다.

## 남은 사항
일반음식점 수집 코드 제거와 이용 가능한 초기 원산지 자료 확보는 후속 작업입니다. 현재 실제 업소·원산지 자료는 없으며 가상 데이터를 실제 정보로 대체하지 않습니다. 운영 배포는 수행하지 않습니다.

## 관련 이슈
확정된 김치 지도 범위 외 코드·문서·데이터를 정리하라는 사용자 요청을 반영합니다.
