## 변경 목적
사용자가 공개 업소의 잘못된 정보를 신고하고 본인과 관리자가 처리 결과를 확인하도록 합니다.

## 주요 변경 사항
원산지 변경·폐업·위치·연락처 오류 신고, 선택적 사진 첨부, 본인 목록·상세, 관리자 처리 화면을 제공합니다. 요청 키와 본문 해시로 중복 접수를 막고 회원별 신고 제한을 적용합니다. 관리자 처리에는 버전·사유·불변 감사 이력을 남기며 선택적 원산지 근거 철회를 같은 트랜잭션에 포함합니다. 기존 원산지 정정 후 지도 캐시 무효화 키도 수정합니다.

## 검증 방법과 실제 결과
전체 검증에서 백엔드 단위·실제 데이터베이스와 Redis 통합·외부 계약·공간검색 성능·API 계약·빌드가 통과했습니다. 프론트 테스트 55건과 모바일·PC 브라우저 20건이 통과했습니다. 추가 사진 소유권과 처리 후 비공개 회귀를 포함한 신고 통합 5건도 통과했으며 최종 준비 검사에서 전체 검증을 재확인합니다.

## 데이터·보안 영향
신고는 본인과 관리자만 조회합니다. 접수만으로 공개 정보가 바뀌지 않으며 다른 업소의 근거 정정은 거부합니다. 동시 처리는 한 요청만 성공합니다. 허가가 확인되지 않은 외부 자료를 수집·저장·공개하지 않습니다.

## 호환성·마이그레이션
열다섯 번째 마이그레이션으로 오류 신고·첨부 연결·처리 이력을 추가합니다. 기존 제보와 검수 이력을 변경하지 않습니다. 생성한 API 계약과 프론트 타입을 갱신합니다.

## 남은 사항
일반 업소 정보 정정, 김치 공개 자격 강화, 불필요한 기존 수집 코드 정리, 허용된 초기 데이터 확보가 남아 있습니다. 신고 화면에서 원산지 정정은 별도 관리 화면으로 연결되며 선택적 원자적 정정 입력은 API에 제공됩니다. 실제 외부 로그인과 운영 배포는 이번 검증에 포함하지 않습니다.

## 관련 이슈
사용자가 확정한 정보 오류 신고와 관리자 처리 요구를 반영합니다.
