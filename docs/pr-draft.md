## 변경 목적
국내산 쌀만 확인되거나 김치인지 확인하지 않은 품목이 업소 공개 자격을 부여하던 조건을 확정한 김치 지도 범위에 맞춥니다.

## 주요 변경 사항
품목에 명시적인 김치 분류를 추가하고 유효한 국내산 배추·고춧가루만 공개 자격에 사용합니다. 검색과 상세도 확인된 김치 품목만 보여줍니다. 관리자 승인은 해당 김치 품목·용도의 표시판 확인을 요구하며 서버에서도 누락을 거부합니다. 승인 뒤 지도 캐시를 갱신합니다.

## 검증 방법과 실제 결과
공개 자격·원산지 모델·공간검색·검수 회귀를 실행했습니다. 기존 쌀 보조 자료에 의존한 집계 실패를 발견해 김치 자료와 실제 검수 대상 집계로 수정했습니다. 쌀과 분류 미확인 배추의 공개 거부, 같은 품목 결합, 승인 확인 누락 거부를 검사합니다. 프론트 55건 통과. 전체 검증에서 포맷과 지정 테스트 집계 오류를 발견해 수정했고 지정·공개 자격 통합 재검증이 통과했습니다. 최종 준비에서 전체 검증을 재확인합니다.

## 데이터·보안 영향
기존 원산지·검토 이력은 보존합니다. 자료 이름으로 김치 여부를 추정하거나 실제 자료를 새로 수집하지 않습니다. 미확인 품목은 공개되지 않으며 국내산 근거가 없는 업소의 좋아요·상세 접근도 거부합니다.

## 호환성·마이그레이션
열여섯 번째 마이그레이션은 기존 품목 분류를 미확인으로 설정합니다. 이전 자료는 명시적인 재검토 전까지 공개되지 않으며 일괄 추정 보정하지 않습니다. 승인 API에 김치 품목 확인 항목을 추가하고 생성 계약과 화면을 갱신합니다.

## 남은 사항
기존 미확인 품목의 관리 재분류 절차, 일반음식점 수집 코드·자료 정리, 허용된 초기 원산지 자료 확보는 후속 작업입니다. 외부 실연동과 운영 준비 완료를 뜻하지 않습니다.

## 관련 이슈
국산 배추·국산 고춧가루·둘 다 국산의 전국 김치 지도라는 확정 요구를 적용합니다.
