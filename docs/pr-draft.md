## 변경 목적
오류 신고를 처리하면서 실제 업소 정보도 수정할 수 있도록 관리자 정정 기능을 제공합니다.

## 주요 변경 사항
이름·주소·위치·업소 전화번호·영업 상태 정정과 최근 100건의 변경 전후 이력 화면을 추가했습니다. 신고 처리에서 업소 정정을 선택하면 같은 트랜잭션에 반영합니다. 폐업은 공개에서 제외하고 재개 시에도 기존 원산지 공개 조건을 적용합니다.

## 검증 방법과 실제 결과
대상 백엔드 통합 테스트와 프론트엔드 59건을 통과했습니다. 관리자 권한·명시적 위치 및 전화 확인·버전 충돌·불변 감사·폐업 공개 제외·재개·신고 연계 원자성을 검증합니다. 전체 검증 결과는 계획과 검증 기록에 갱신합니다.

## 데이터·보안 영향
변경한 필드만 자동 수집 덮어쓰기로부터 보호합니다. 변경하지 않은 전화 출처와 좌표 확인 상태를 보존합니다. 신고가 가리키는 업소를 서버에서 결정하고 일반 회원에게 관리자 조회와 쓰기를 허용하지 않습니다. 제삼자 자료 수집은 없습니다.

## 호환성·마이그레이션
18번 마이그레이션에서 관리자 정정 출처와 불변 감사 테이블을 추가합니다. 기존 원산지 승인일과 제보 근거는 변경하지 않습니다. OpenAPI와 생성 타입을 갱신했습니다.

## 남은 사항
이용 조건을 확인한 초기 원산지 자료가 없어 실제 업소 데이터는 없습니다. 외부 실연동과 배포 완료를 의미하지 않습니다.

## 관련 이슈
지도 등록 이후 정보 오류 신고를 관리자가 실제 정정까지 처리할 수 있어야 한다는 요구를 반영합니다.
