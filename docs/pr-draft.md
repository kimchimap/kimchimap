## 변경 목적
카카오 계정 인증을 서비스 세션과 연결하고 브라우저에서 로그인 상태를 복구·폐기합니다.

## 주요 변경 사항
Spring Security의 OAuth 코드 교환과 PKCE·OIDC 검증을 연결했습니다. 인가 요청은 브라우저와 묶어 Redis에 잠시 보관한 뒤 한 번만 소비하며 카카오 토큰은 보관하지 않습니다. 로그인·복구·로그아웃 화면과 메모리 토큰, 탭 갱신 잠금, 사용자 캐시 정리를 구현했습니다.

## 검증 방법과 실제 결과
전체 하네스 검증을 통과했습니다. 백엔드 단위·계층 검사 26건, 실제 PostGIS·Redis 통합 45건, 외부 계약 5건, 성능 1건, 프론트 테스트 16건, 모바일·PC 브라우저 6건, 하네스 28건이 통과했습니다. 통제된 공급자로 코드 교환과 잘못된 인증 요청 거부를 확인했습니다.

## 데이터·보안 영향
브라우저 저장소에 토큰을 쓰지 않으며 갱신·로그아웃에 CSRF 보호를 유지합니다. 실제 카카오 사용자 로그인은 아직 확인하지 않았습니다. 사용자 프로필·이메일을 추가 수집하지 않습니다.

## 호환성·마이그레이션
DB 변경은 없습니다. 카카오 설정과 로컬 비밀 파일을 사용하며 키가 없으면 공개 기능을 유지하고 로그인은 거부합니다.

## 남은 사항
즐겨찾기·증빙 이미지·제보·검수와 전체 지도 화면을 이어서 구현합니다. 실제 지도·카카오 계정 검증, 데이터 이용 허락과 출시 전 점검은 별도로 남아 있습니다.

## 관련 이슈
별도 등록된 이슈는 없습니다. 작업 계획과 검증 기록을 갱신했습니다.
