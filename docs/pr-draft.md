## 변경 목적
기존 서버의 전체 세션 로그아웃과 회원 탈퇴를 사용자가 화면에서 실행할 수 있도록 연결합니다.

## 주요 변경 사항
계정 관리 화면과 탈퇴 확인을 추가하고 처리 중 중복 요청을 차단합니다. 전체 로그아웃과 탈퇴는 서버 성공 후 메모리 토큰·사용자 캐시를 정리하며 다른 탭에 알립니다. 서버 실패는 완료로 표시하거나 자동 재전송하지 않습니다.

## 검증 방법과 실제 결과
전체 검증 통과: 단위 37·통합 83·내부 계약 7·성능 1·프론트 64·브라우저 24·하네스 29건. 탈퇴 확인·중복 차단·실패 재시도와 토큰·캐시 정리를 검증했습니다. 실제 API의 탈퇴 후 모든 세션 거부·재가입 식별자 분리, 모바일·PC 화면의 재시도 검증을 추가하고 통과했습니다.

## 데이터·보안 영향
현재 탈퇴는 기존 계정 비활성화와 카카오 식별자 연결 제거입니다. 같은 카카오로 재가입하면 새 회원이며 과거 자료 소유권을 복원하지 않습니다. 공개 근거·검수 이력이 즉시 모두 삭제되는 것으로 안내하지 않습니다.

## 호환성·마이그레이션
기존 서버 API를 사용하며 스키마 변경은 없습니다. 현재 기기 로그아웃의 쿠키 기반 재시도는 유지합니다.

## 남은 사항
개인정보 보유기간과 삭제 요청 절차는 출시 전 확정이 필요합니다. 실제 카카오 사용자 로그인 완료는 별도 확인입니다.

## 관련 이슈
회원이 자신의 로그인 세션과 계정을 관리할 수 있어야 한다는 요구를 반영합니다.
