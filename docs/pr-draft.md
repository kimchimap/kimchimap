## 변경 목적
로그인한 사용자가 업소를 즐겨찾기에 저장하고 원산지 증빙 사진을 안전하게 첨부할 수 있게 합니다.

## 주요 변경 사항
본인 즐겨찾기 추가·삭제·페이지 조회와 화면을 구현했습니다. 사진의 실제 내용·형식·크기·해상도를 검사하고 메타데이터를 제외한 이미지로 재생성합니다. 원본과 정제본을 비공개로 저장하며 소유자와 관리자만 조회합니다. 업로드 동시성·요청 제한과 미연결·고아 파일 정리를 추가했습니다.

## 검증 방법과 실제 결과
최종 전체 검증을 통과했습니다. 단위·계층 33건, 실제 PostGIS·Redis 통합 49건, 외부 계약 5건, 성능 1건, 프론트 22건, 모바일·PC 브라우저 8건, 하네스 28건이 통과했습니다. 최초 포맷 실패를 수정한 뒤 전체 검증을 다시 실행했습니다. 사진 위장·픽셀 폭탄·메타데이터 제거·소유권·파일 충돌·정리 동작을 확인했습니다.

## 데이터·보안 영향
사진은 아직 공개하지 않습니다. 제보 연결과 관리자 개인정보 검토 후 공개 승격은 다음 작업입니다. 실제 제보 사진과 비밀값을 커밋하지 않았습니다. 협회 데이터 이용 허가는 아직 없으므로 해당 자동 수집을 진행하지 않습니다.

## 호환성·마이그레이션
여섯 번째 마이그레이션으로 즐겨찾기와 미디어 메타데이터를 추가합니다. 기존 마이그레이션은 수정하지 않았습니다. 운영 사진 저장소는 웹 루트 밖의 명시적인 경로가 필요합니다.

## 남은 사항
제보 작성·수정·철회, 관리자 검수와 원산지 공개 반영을 이어서 구현합니다. 실제 지도와 카카오 계정 로그인 완료, 공개 운영 전 정책 점검은 별도로 남아 있습니다.

## 관련 이슈
별도 등록된 이슈는 없습니다. 작업 계획과 검증 기록을 갱신했습니다.
