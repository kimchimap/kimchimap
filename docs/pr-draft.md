## 변경 목적
관리자가 허용된 업소 데이터 소스의 처리 상태와 오류를 확인하고 제한된 범위로 수집을 재개할 수 있게 합니다.

## 주요 변경 사항
관리자 수집 상태·소스·처리 이력·격리 목록과 재실행 API 및 화면을 구현했습니다. 동일 요청의 중복 예산 증가를 차단하고 실행 사유·사용자를 불변 감사에 남깁니다. 정기 수집 생성과 접수된 작업의 비동기 처리를 분리했습니다. 기본 변경 계획만 출력하는 서버 회원 권한 도구를 추가했습니다.

## 검증 방법과 실제 결과
전체 검증을 통과했습니다. 백엔드 단위·계층 37건, 실제 PostGIS·Redis 통합 58건, 외부 계약 5건, 성능 1건, 프론트 30건, 모바일·PC 브라우저 12건, 하네스 28건이 통과했습니다. 계약·포맷·린트·타입·양쪽 빌드도 확인했습니다.

## 데이터·보안 영향
관리자 권한과 소스 이용 조건·인증키 설정을 확인합니다. 화면에는 인증키·원문 개인정보·내부 잠금 식별자를 노출하지 않습니다. 재실행은 기본 2페이지·최대 100페이지, 관리자별 시간당 10회로 제한합니다. 임시 사진 정리가 외부 정기 수집 설정에 종속된 문제를 수정했습니다. 실제 회원을 임의로 관리자로 지정하지 않았습니다.

## 호환성·마이그레이션
여덟 번째 마이그레이션으로 수집 요청·불변 감사와 만료 조회 인덱스를 추가합니다. 기존 마이그레이션은 변경하지 않았습니다. 생성 OpenAPI와 프론트 타입을 동기화했습니다. 자동 정기 수집은 기본 꺼짐을 유지합니다.

## 남은 사항
원산지 정정·지정 정보·업소 매칭 검토와 지도 전체 화면을 이어서 구현합니다. 협회 자료는 수집·재게시 허가가 없어 수집하지 않습니다. 실제 카카오 로그인·지도 전체 연결과 공개 운영 전 보관 정책·라이선스 결정은 남아 있습니다.

## 관련 이슈
별도 등록된 이슈는 없습니다. 계획·설계 결정·실행 문서를 갱신했습니다.
