## 변경 목적
확정된 김치 지도 범위에 맞지 않는 일반음식점 전체 수집 API의 실행 코드를 제거합니다.

## 주요 변경 사항
전용 URL·HTTP 호출부·필드 파서·키 전달을 제거했습니다. 실제 등록된 어댑터가 없으면 실패하는 내부 경계를 두고 관리자 화면은 수집기 미구현 상태를 표시합니다. 내부 표준 입력의 좌표계를 보존하며 기존 수집 엔진의 재개·중복 방지·격리·경합 검증을 유지합니다. 중단된 소스의 과거 매칭 관찰본도 재등록할 수 없도록 차단합니다.

## 검증 방법과 실제 결과
전체 검증이 통과했고 추가 자기 검토로 과거 관찰본의 좌표계 누락 경계를 보강했습니다. 첫 추가 테스트에서 명확한 충돌 대신 내부 오류가 반환된 것을 발견해 입력 구조를 먼저 검증하도록 수정했습니다. 수정 후 추가 통합 7건이 통과했고 최종 준비에서 전체 검증을 재확인합니다. 하네스는 폐기 키를 기존 파일에 보존하되 실행 환경에 전달하지 않는지 검사합니다.

## 데이터·보안 영향
실제 외부 원산지 자료를 새로 수집하지 않습니다. 등록된 실사용 원산지 어댑터는 없습니다. 기존 비밀 파일은 덮어쓰지 않습니다. 허용하지 않은 내부 입력 필드는 거부하고 좌표계·날짜를 추정하지 않습니다.

## 호환성·마이그레이션
수집 상태의 인증키 설정 여부를 어댑터 등록 여부로 대체하고 생성 계약을 갱신했습니다. 관찰본은 원래 좌표계를 명시적으로 저장합니다. 좌표계가 빠진 과거 관찰본은 재검토 전 반영을 거부합니다. 새 DB 마이그레이션은 없습니다.

## 남은 사항
소스별 이용 조건·실제 명세와 필드를 확인한 원산지 수집기는 아직 없습니다. 내부 어댑터 계약 테스트는 외부 원산지 API 계약이나 실연동 성공을 의미하지 않습니다. 새 HTTP 어댑터를 만들 때 해당 제공기관의 계약과 네트워크 보안·응답 크기·호출 제한을 다시 검증해야 합니다.

## 관련 이슈
불필요한 기존 코드와 자료를 정리하고 이용 가능한 데이터만 사용하라는 요청을 반영합니다. 폐기 API 전용 계약과 미사용 HTTP 본문 도구 테스트는 기능 제거에 따라 정리했으며 수집 엔진 회귀를 축소하지 않았습니다.
