## 변경 목적
확정한 전국 김치 지도를 시작 화면으로 제공하고 위치 선택에서 신규 업소 제보까지 연결합니다.

## 주요 변경 사항
국산 배추·국산 고춧가루·둘 다 국산의 세 필터와 같은 품목 조합 검색을 제공합니다. 지도·목록·상세 선택과 모바일 하단 시트를 연결하고 지도 클릭 또는 키보드 대체 선택으로 신규 제보 위치를 전달합니다. 좋아요 수·내 목록, 전화 연결, 실제 승인 인증 날짜와 외부 지정일을 구분합니다. 범용 필터와 연락처 전용 중복 상세 화면을 제거했습니다.

## 검증 방법과 실제 결과
프론트 51건, 승인일 일치를 포함한 제보 통합 10건과 모바일·PC 브라우저 18건 통과. 전체 검증에서 발견한 린트·테스트 타입·브라우저 캐시 기대값 오류를 수정했습니다. 최종 준비에서 전체 검사와 새 좋아요 표시 단언을 재확인합니다. 모바일 화면 캡처와 공식 지도 클릭 이벤트 계약을 확인했습니다.

## 데이터·보안 영향
지도 객체를 서버 데이터 캐시에 넣지 않습니다. 지도 변경 검색의 취소·늦은 응답 처리·이벤트 정리를 유지합니다. 브라우저에는 지도 JavaScript 키만 전달하며 테스트는 외부 지도를 대체합니다. 실제 초기 원산지 데이터는 추가하지 않았고 허용 조건이 확인된 자료만 사용할 계획입니다.

## 호환성·마이그레이션
열네 번째 마이그레이션은 승인 시각 조회 인덱스를 추가합니다. 인증 날짜는 실제 승인 이력이며 수집일·원산지 검토일과 별개입니다. 생성 API 계약을 갱신했습니다. 이전 연락처 전용 경로는 원산지 상세 경로로 통합합니다.

## 남은 사항
정보 오류 신고, 김치 외 공개 자격·불필요한 일반음식점 수집 코드와 자료 정리, 허용된 초기 데이터 확보가 남아 있습니다. 운영 배포와 외부 사용자 로그인 검증은 수행하지 않았습니다.

## 관련 이슈
사용자가 확정한 전국 지도·세 필터·인증 날짜·위치 제보 흐름을 반영합니다.
