## 변경 목적
확정된 전국 김치 지도 컨셉을 제품 계약에 반영하고 기존 즐겨찾기를 좋아요로 통합합니다.

## 주요 변경 사항
회원별 좋아요 등록·취소·내 목록과 비로그인 공개 합계를 제공합니다. 기존 즐겨찾기 경로와 화면은 제거하고 서버 계약에서 프론트 타입을 재생성했습니다. 지도 필터·인증 날짜·신규 제보·오류 신고·초기 데이터 소스의 구현 기준을 정리했습니다.

## 검증 방법과 실제 결과
단위·계층 37건, 실제 DB·Redis 통합 67건, 계약 5건, 성능 1건, 프론트 39건과 모바일·PC 브라우저 12건 통과. 최초 실패 원인을 수정한 뒤 재검증했습니다. 브라우저 실행 파일 설치와 전용 포트 구성을 로컬에서 확인했습니다. 계약 일치·포맷·린트·타입·양쪽 빌드도 통과했습니다.

## 데이터·보안 영향
회원당 업소 하나의 좋아요 제약과 멱등 변경을 유지합니다. 공개 합계는 공개 가능한 업소에만 제공하며 회원 식별자와 개인 목록을 노출하지 않습니다. 협회 자료의 일괄 수집·재게시 허가는 아직 확인되지 않았고 실제 원산지 초기 데이터는 추가하지 않았습니다.

## 호환성·마이그레이션
열두 번째 마이그레이션으로 기존 개인 목록 테이블을 좋아요 테이블로 이름 변경하고 집계 인덱스를 추가합니다. 기존 마이그레이션은 변경하지 않습니다. 이전 즐겨찾기 경로는 새 좋아요 경로로 교체합니다.

## 남은 사항
위치 기반 신규 등록, 정보 오류 신고, 지도와 세 가지 필터, 인증 날짜 표시, 허용된 지정 자료 수집, 불필요한 수집 코드·데이터 정리를 다음 작업으로 진행합니다. 서비스 전체 완료나 외부 실연동 완료를 뜻하지 않습니다.

## 관련 이슈
사용자가 확정한 전국 김치 지도 컨셉을 반영합니다.
