## 변경 목적
원산지 근거가 없는 일반 음식점이 지도·상세에 노출되던 범위 오류를 수정합니다. 국내산 사용 항목이 확인된 업소만 공개합니다.

## 주요 변경 사항
특정 품목·용도의 유효한 승인 국내산 근거가 있어야 검색·상세·즐겨찾기·정제 증빙 이미지를 공개합니다. 마지막 근거의 철회·만료·상충도 반영합니다. 원산지 필드가 없는 일반음식점 소스의 신규·예약·기존 대기 작업 실행을 차단하고 관리자 안내·생성 계약을 갱신했습니다.

## 검증 방법과 실제 결과
전체 검증 통과. 백엔드 단위·계층 37건, 실제 DB·Redis 통합 67건, 외부 합성 계약 5건, 성능 1건, 프론트 39건, 모바일·PC 브라우저 12건, 하네스 28건 통과. 검사 삭제나 건너뛰기 없이 기존 테스트를 새 제품 기준에 맞게 변경했습니다. 로컬 저장 자료 199개 중 공개 자격 0개, 과거 수집 취소, 수집 명령의 의도한 거부를 확인했습니다.

## 데이터·보안 영향
공공 API의 기술적 호출 성공을 국내산 데이터 확보로 취급하던 문서를 정정했습니다. 실제 원산지 자료는 아직 없으며 협회 허가도 없습니다. 과거 자료는 감사 이력으로 보존하고 공개하지 않습니다. 미등록 업소는 후속 제보·검수 구현으로 연결합니다.

## 호환성·마이그레이션
열한 번째 마이그레이션에 공통 공개 자격 함수와 과거 수집 작업 취소를 추가했습니다. 기존 마이그레이션은 수정하지 않았습니다. 국내산 근거 없는 기존 상세 주소는 찾을 수 없음 응답으로 바뀝니다. 수집 소스 계약에 국내산 선별 지원 여부를 추가했습니다.

## 남은 사항
미등록 업소 제보·검수·공개 흐름을 다음 작업으로 구현합니다. 지도 작업은 별도 브랜치에 보존했으며 이 수정과 통합 후 검증합니다. 적합한 외부 원산지 자료와 이용 조건 확보가 필요합니다. 릴리스·배포·CI/CD는 포함하지 않습니다.

## 관련 이슈
사용자가 확정한 국내산 사용 업소 중심 범위 정정입니다. 계획·설계·데이터 소스·검증 기록을 갱신했습니다.
