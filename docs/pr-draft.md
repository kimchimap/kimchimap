## 변경 목적
관리자가 허가된 지정 제도의 실제 기준을 보존하고 애매한 외부 업소를 비교하여 지점 연결을 결정할 수 있게 합니다.

## 주요 변경 사항
지정 정보 생성·수정·취소와 불변 이력, 지정 전용 이용 허가 검사를 추가했습니다. 수집 관찰본·후보 비교와 기존 업소 연결 또는 별도 업소 생성을 구현했습니다. 관리자 화면과 생성 OpenAPI 타입을 연결했습니다.

## 검증 방법과 실제 결과
전체 검증을 통과했습니다. 단위·계층 37건, 실제 PostGIS·Redis 통합 65건, 외부 계약 5건, 성능 1건, 프론트 38건, 모바일·PC 브라우저 12건, 하네스 28건이 통과했습니다. 서로 다른 외부 식별자가 같은 지점에 동시에 연결되는 경쟁 조건을 보강한 뒤 실제 동시 요청의 단일 성공을 검증했습니다.

## 데이터·보안 영향
관리자 권한·허가·버전을 서버에서 확인합니다. 지정으로 식재료 원산지를 만들지 않으며 외부 식별자와 지점 충돌을 거부합니다. 검토 시각을 수집 시각으로 바꾸지 않습니다. 관찰본과 변경 감사를 보존합니다. 협회 허가는 아직 없으며 실제 자료를 수집하지 않았습니다.

## 호환성·마이그레이션
열 번째 마이그레이션으로 지정 전용 이용 범위와 불변 변경 이력·매칭 관찰본을 추가합니다. 기존 마이그레이션은 수정하지 않았습니다. 과거 관찰본 없는 후보는 다음 허용 수집 전 확정할 수 없습니다.

## 남은 사항
지도·목록·상세 전체 화면과 실제 연결 검증을 이어서 구현합니다. 실제 카카오 사용자 로그인과 지도, 협회 이용 허가, 라이선스 결정은 별도로 남아 있습니다. 배포와 CI/CD는 추가하지 않았습니다.

## 관련 이슈
별도 등록된 이슈는 없습니다. 계획·설계 결정·검증 문서를 갱신했습니다.
