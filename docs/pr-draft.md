## 변경 목적
미등록 가게의 위치와 원산지 표시판 사진을 제보하고 관리자 승인 시 지도에 등록할 수 있도록 업소 생성 경계를 추가합니다.

## 주요 변경 사항
기존 업소 또는 신규 업소 중 하나로 제보합니다. 신규 제출에는 이름·주소·좌표·선택 전화번호를 보관하며 승인 전 업소는 생성하지 않습니다. 관리자가 위치를 확인하고 국내산 배추 또는 고춧가루 근거를 승인하면 업소·원산지·검수 이력을 함께 반영합니다. 신규 목록·수정·철회와 승인 날짜·등록 업소 연결을 제공합니다.

## 검증 방법과 실제 결과
단위 37건, 통합 70건, 계약 5건, 성능 1건, 프론트 41건과 모바일·PC 브라우저 14건 통과. 기존 승인 요청의 선택 필드 처리와 신규 양식의 선택 업소 식별자 타입 오류를 수정했습니다. 동일 업소의 두 제보 승인 경합 검사를 추가하고 최종 검증합니다.

## 데이터·보안 영향
승인 전 공개하지 않습니다. 업소 생성·원산지·감사가 같은 트랜잭션이며 실패 시 함께 롤백합니다. 같은 이름·주소의 등록 경합은 데이터베이스 잠금과 중복 확인으로 거부하며 자동 병합하지 않습니다. 일반 사용자에게 관리자 권한이나 인증 우회를 추가하지 않습니다. 이용 조건이 확인된 데이터만 사용한다는 사용자 결정을 기록했습니다.

## 호환성·마이그레이션
열세 번째 마이그레이션은 승인 전 제보의 업소 식별자를 비워 둘 수 있도록 하되 승인 상태에는 업소 연결을 강제합니다. 기존 제출본·마이그레이션은 수정하지 않습니다. 서버 계약에서 프론트 타입을 재생성했습니다.

## 남은 사항
지도 클릭 버튼의 연결은 지도 통합 작업에서 진행합니다. 정보 오류 신고, 세 가지 김치 필터, 불필요한 수집 코드·자료 정리, 이용 조건이 확인된 초기 데이터 확보가 남아 있습니다. 외부 초기 데이터 수집 성공이나 서비스 전체 완료를 뜻하지 않습니다.

## 관련 이슈
사용자가 확정한 위치 선택·표시판 사진·관리자 승인 등록 흐름입니다.
