## 변경 목적

업소와 원산지를 메뉴·용도·근거별로 저장하고 공개 조회하는 기반을 구현했습니다. 상충하는 주장이나 비공개 근거를 섞어 국내산으로 단정하지 않습니다.

## 주요 변경 사항

Flyway 추가 마이그레이션으로 업소·카탈로그·품목·원산지·국가 구성·근거·지정을 분리했습니다. 원산지 기록과 구성은 수정할 수 없고 혼합 관계는 DB 커밋 시에도 검증합니다. 공개 상세와 카탈로그 API, 오류 응답, 생성 계약을 추가했습니다.

## 검증 방법과 실제 결과

백엔드 단위와 계층 검사 12개, 실제 PostGIS와 Redis 통합 13개를 통과했습니다. `verify-unit origin-model`에서 하네스 28개·프론트 2개·모바일 및 PC E2E 2개·API 생성 비교·양쪽 빌드까지 통과했습니다.

## 데이터·보안 영향

실제 업소·원산지 초기값은 없습니다. 참조 카탈로그만 등록합니다. 비공개 증빙은 응답하지 않으며, 비공개 승인 기록의 상충도 공개 판정에 반영합니다. 제공받은 키는 Git 제외된 로컬 파일에만 저장했습니다.

## 호환성·마이그레이션

기존 마이그레이션을 보존하고 새 파일을 추가했습니다. 앱 계정의 스키마 변경 제한을 유지합니다. 상세 조회 상한을 초과하면 일부 정보로 잘못 판정하지 않고 오류를 반환합니다.

## 남은 사항

공간 검색·수집·로그인·관리자 정정·화면 연결은 다음 작업입니다. 카카오 설정은 사용자가 완료를 확인했으며 공공 API 활용 승인도 사용자가 확인했습니다. 실제 외부 호출은 아직 미확인입니다.
