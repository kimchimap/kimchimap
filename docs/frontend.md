# 화면과 클라이언트 계약

[제품 계약](product.md)을 따른다. 사용자 화면과 오류는 한국어이며 API 타입은 OpenAPI에서 생성한다. 관리자 화면 접근 경계는 사용 편의 기능이고 실제 인가는 서버에서 수행한다.

## 지도·목록·상세

`/`는 전국 지도와 목록이다. 모바일에서는 하단 시트, PC에서는 지도 옆 목록을 제공한다. 국산 배추·국산 고춧가루·둘 다 국산 세 필터를 제공하고 기본은 둘 다 국산이다. 두 재료는 같은 김치 품목·용도에서 충족해야 한다. 상세를 열고 닫을 때 해당 지도 화면의 검색·선택 상태와 포커스를 유지한다. 페이지를 새로 열 때 검색 URL에 모든 상태가 저장되는 것으로 설명하지 않는다.

`/restaurants/:id`는 원산지 품목·용도·출처·원문·관찰일·수집일·제보 승인일·지정일, 좋아요 수와 공개 업소 전화번호를 표시한다. 유효한 번호만 `tel:` 링크를 만들며 전화 연결은 기기 지원에 따른다. 미확인·수입·혼합·분쟁·만료를 구분한다. `/about/data`는 근거 수준과 현재 실제 데이터 미확보 상태를 안내한다.

지도 빈 위치 클릭 또는 ‘지도 중심 위치 선택’으로 제보 위치를 고른다. 선택 마커와 ‘이 위치 제보하기’를 제공한다. 현재 위치는 사용자 동작과 권한 허용 뒤 요청하며 위치 이력을 기본 저장하지 않는다. 위치 거부·시간 초과에도 지역 선택·지역 검색·지도 이동을 사용할 수 있다.

SDK는 단일 Promise 로더로 중앙화한다. StrictMode 재실행에 안전하게 지도·마커·이벤트를 정리하고 지도 이동 요청은 debounce·취소·오래된 응답 무시를 적용한다. SDK LatLng는 위도/경도, DB Point는 경도/위도다. 로고와 출처를 보존한다. SDK 실패·키 미설정에는 안내와 목록을 유지하며 가짜 지도를 사용하지 않는다.

## 회원·제보·좋아요

`/login`→카카오→`/auth/complete`에서 토큰 없는 안전한 경로로 복귀하고 서비스 세션을 복구한다. Access Token은 메모리, Refresh Token은 HttpOnly 쿠키다. `/account`에서 전체 기기 로그아웃·탈퇴를 실행한다. 탈퇴 확인 전 차단하고 실패를 성공으로 표시하지 않는다. 기존 회원 연결을 복원하지 않으며 공개 근거·감사는 즉시 모두 삭제되지 않음을 안내한다.

기존 업소 제보는 `/reports/new?restaurantId=...`, 신규 위치는 `/reports/new?latitude=...&longitude=...`다. 이름·주소·선택 전화번호·김치 품목/용도·관찰일·배추/고춧가루 원산지·표시판 사진·공개 동의를 받는다. 다른 식재료 탐색 양식은 제공하지 않는다. 확장 가능한 내부 카탈로그와 기존 기록을 임의 삭제하거나 김치 근거로 재분류하지 않는다.

`/reports`·`/reports/:id`는 본인 상태·검수 사유·비공개 사진과 대기/보완 상태 수정·철회를 제공한다. 업로드 성공은 제보 접수가 아니다. 실패 재시도는 같은 본문에 같은 요청 키를 사용하고 충돌은 최신 내용을 확인하도록 안내한다. Blob URL은 화면 정리 시 해제한다.

`/likes`는 내 좋아요 목록이며 상세에서 등록·취소하고 공개 합계를 확인한다. 별도 즐겨찾기는 없다. `/information-reports`·상세는 본인 오류 신고와 처리 결과를 제공하며 신고는 공개 업소 상세에서 시작한다.

## 관리자

- `/admin/reports`: 제출 사진·품목·용도·관찰일을 검토하고 승인·반려·보완 요청한다. 김치 적용 확인이 필요하고 신규 업소는 위치 일치도 확인한다. 사진별 정제본 공개 검토는 별도다.
- `/admin/information-reports`: 오류 신고를 처리한다. 업소 정정을 선택하면 같은 요청에 반영하며 원산지 정정 화면으로도 연결한다. 선택적 원산지 철회 API 입력 자체는 이 폼에 노출하지 않는다.
- `/admin/restaurants/:id`: 이름·주소·위치·영업 상태·전화번호를 정정하고 최근 100건의 변경 전후 이력을 확인한다. 폐업은 공개 제외이며 근거·날짜를 보존한다.
- `/admin/origins`: 동일 품목·용도·식재료의 근거를 검토하고 잘못된 기록을 사유와 함께 철회한다. 새 원산지는 제보·검수로 추가한다.
- `/admin/designations`·`/admin/matches`: 이용 조건과 소스 자격을 확인한 지정·업소 매칭만 처리한다. 현재 허가 없는 목록을 등록하지 않는다.
- `/admin/ingestion`: 소스 허가·실제 어댑터 등록 여부·작업 상태·격리 오류를 확인한다. 현재 실사용 원산지 어댑터가 없으므로 실행 차단을 표시한다.

모든 변경은 진행 중 중복 요청을 막고 버전 충돌 때 입력을 보존한다. 서버 성공 뒤 관련 지도·상세·회원 캐시를 무효화한다.

## 상태·접근성·검증

로딩·빈 결과·네트워크 오류·지도 실패·오래된 정보·분쟁·인증 만료·업로드 실패·검수 충돌을 구분한다. label·키보드·포커스·대비·터치 영역을 제공하고 색상만으로 상태를 표현하지 않는다.

TanStack Query에는 서버 데이터만 저장하고 SDK 객체는 넣지 않는다. private 캐시는 회원 식별자를 포함하고 로그아웃·회원 전환 시 제거한다. 로그아웃 후 남은 보호 요청은 재갱신하지 않는다. 탭 간 잠금이 없는 환경에서는 회전 경합으로 재로그인이 필요할 수 있다.

Vitest/RTL, 모의 API·SDK 경계 브라우저 검사, 실제 서버 연결 PC/모바일 검사, 별도 실제 카카오 smoke를 구분한다. [검증 기록](validation.md)에 실제 실행 결과를 남긴다.
