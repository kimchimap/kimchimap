# 국산김치 자율표시제 데이터 이용 확인 요청문

보낼 곳: 대한민국김치협회 자율표시제 운영 사무국. 공식 홈페이지에 게시된 연락처를 통해 담당 창구를 확인한다. 아래 초안은 아직 발송하지 않았다.

안녕하세요. 국산 배추·고춧가루를 사용하는 김치 제공 업소를 찾는 ‘국산김치맵’을 개발하고 있습니다. 국산김치 자율표시제 지정음식점 정보를 초기 지도 데이터로 사용하고자 다음 이용 범위를 확인 부탁드립니다.

1. 공개 조회 목록의 업소명, 사업장 주소, 업소 대표번호, 지정품목, 지정일, 업소 구분을 자동 수집하여 서비스 DB에 저장하고 지도·목록·상세에 재게시할 수 있는지요?
2. 공식 API·파일 제공 방식이 있는지, 없다면 허용되는 조회 방식·호출량·갱신 주기를 안내 부탁드립니다.
3. 출처 표시 문구·원문 링크·표장 사용 조건, 지정 변경·취소·갱신 정보 제공 여부를 알려 주실 수 있는지요?
4. 일반 음식점의 국산 재료 100% 기준과 고속도로 휴게소 예외를 구분할 수 있는 데이터가 있는지요? 지정 배추김치에 한해 배추·고춧가루가 국내산이라는 필터의 근거로 사용할 수 있는지 확인 부탁드립니다.
5. 소스코드 공개와 데이터 재배포를 분리하여, 원본 목록과 개인정보는 공개 저장소에 넣지 않고 서비스에 필요한 사업장 정보만 표시할 계획입니다. 이 방식에 추가 조건이 있는지요?

제공받은 기준과 실제 지정일을 보존하고 원산지 실물 납품·위생 인증으로 확대 설명하지 않겠습니다. 허용 범위·기간·철회 절차를 문서나 이메일로 회신해 주시면 해당 조건을 준수하겠습니다.
