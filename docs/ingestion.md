# 수집 상태와 구현 경계

2026-11-12 현재 **실사용 가능한 원산지 수집 어댑터는 없다**. 일반음식점 API는 원산지 필드가 없어 호출부·인증키 전달·전용 파서와 응답 fixture를 제거했다. 자율표시제 자료도 수집·저장·재게시 허용 범위를 확인하지 못해 등록하지 않는다. 내부 어댑터 인터페이스와 엔진 테스트를 실제 수집기 완성으로 표시하지 않는다.

## 현재 실행

`./scripts/harness ingest-run`과 관리자 재실행은 확인된 원산지 소스가 없으면 외부 호출 전에 실패한다. `ingest-status`와 관리자 화면은 과거 작업의 상태·집계·오류를 조회한다. `adapterAvailable=false`는 실행할 구현이 없다는 뜻이다. 키만 넣거나 스케줄 설정을 켜도 미구현 소스를 실행할 수 없다. 폐기한 일반음식점 키가 기존 로컬 파일에 있으면 보존하되 하위 프로세스로 전달하지 않는다.

실제 업소·원산지 초기 데이터는 0건이다. 과거 일반음식점 업소·원천 자료는 V17에서 미사용 참조를 확인한 뒤 제거했고 불변 실행 감사는 유지했다. [연동 상태](integrations-status.md)와 [자료 이용 조건](data-sources.md)을 함께 확인한다.

## 보존한 수집 엔진

소스별 어댑터 등록 경계, 실행 이력·DB lease/fencing token, 제한 실행기, 페이지 체크포인트, 재개, 외부 ID 중복 방지, 내용 해시, 격리, 매칭 검토, 관리자 정정 보호를 유지한다. 페이지 쓰기와 체크포인트는 한 트랜잭션이다. 동일 작업의 오래된 lease는 쓰기를 거부한다. 총건수 변경은 실패로 남기고 새 범위를 요구하며 단순 목록 누락을 폐업으로 바꾸지 않는다.

작업 상태는 QUEUED/RUNNING/WAITING/SUCCEEDED/PARTIAL/FAILED/CANCELLED다. PARTIAL은 전체 완료가 아니다. 엔진의 제한된 재시도·지수 백오프·지연 재예약은 통제된 어댑터의 실패로 검증한다. Retry-After 변환·HTTP timeout·응답 크기 제한·SSRF 방어는 **새 실제 HTTP 어댑터 구현 시 필수로 검증할 경계**이며 현재 제거한 HTTP 클라이언트가 이를 제공한다고 설명하지 않는다.

현재 작업 저장소의 오래된 일반음식점 소스·기본 증분 기간은 실행 이력 호환을 위한 구조다. 새 소스가 확보되면 원천 갱신 주기·페이지 일관성·증분 기준에 맞춰 작업 저장소와 정책까지 연결해야 한다. 인터페이스 구현 클래스 하나를 추가하는 것만으로 새 수집이 자동 활성화되지는 않는다.

## 내부 표준 입력

SourceAdapter는 이미 이용 조건과 공식 명세를 확인한 공급자의 데이터를 SourceRestaurant 내부 필드로 변환한다. 이는 외부 API 명세가 아니다. externalId, name, address, businessStatus, originalStatus, x, y, coordinateSrid, phone, sourceUpdatedAt, sourceModifiedAt만 받으며 알 수 없는 필드는 거부한다. 원천 날짜를 ISO UTC Instant로 바꿀 책임은 소스 어댑터에 있다. 좌표계는 필수이며 5174로 추정하지 않는다. 원래 SRID와 좌표를 저장하고 실제 변환 결과를 별도로 검증한다.

공개는 김치 품목·국내산 배추/고춧가루·근거·검수 정책을 통과한 기록만 가능하다. 업소 기본정보 입력만으로 공개 자격을 만들지 않는다. 사진 제보 승인도 실물 납품 인증과 다르다.

## 검증과 후속 조건

`test-contract`는 등록되지 않은 어댑터 거부, 잘못된 페이지·중복 소스 등록, 내부 표준 입력·날짜·좌표계 보존을 확인한다. 합성 자료만 사용하며 실제 외부 원산지 응답 계약이나 호출 성공을 뜻하지 않는다. 기존 엔진의 실제 PostGIS 통합 회귀는 재시도·재개·멱등·실패 롤백·경합·정정 보호를 유지한다.

새 소스를 채택할 때는 공식 URL·필드·권한·키·쿼터·저장/재게시·출처 조건·확인일을 먼저 기록한다. 허용 응답 fixture와 실제 제한 호출→정규화→저장→공개 조회를 별도로 확인한다. 로그인·CAPTCHA·차단 우회와 사용자 입력 URL 임의 수집은 금지한다.
