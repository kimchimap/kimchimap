## 미완료·외부 조건

1. 허용된 실제 원산지 초기 자료와 실사용 수집기는 없다. 협회 자동 수집·저장·재게시 허가가 확인되지 않았으며 사용자는 이용 가능한 자료만 사용하라고 확정했다. 다른 자료도 해당 목록·필드·이용 조건을 확인해야 한다.
2. 실제 카카오 로그인은 2026-11-12 사용자 화면 확인과 로컬 회원·세션 생성으로 검증했다. 실제 외부 계정의 로그아웃·탈퇴까지 검증한 것은 아니다.
3. 라이선스, 개인정보 보유기간·삭제 요청 절차, 운영 비밀·도메인·백업·배포 검증은 출시 전 결정·확인 사항이다. 이번 작업에서 배포·CI/CD를 만들지 않는다.
4. 과거 모호한 김치 scope는 자동 추정하지 않는다. 현재 실제 원산지 레코드는 0건이며 향후 과거 자료 도입 시 명시적 재분류 검토가 필요하다.

데이터 수집 재개는 [소스 장부](../../data-sources.md)의 권한·명세·원산지 적용 범위 확인 → 실제 어댑터·계약 → 제한 호출·저장·공개 증거 순서다. 단순 설정 변경으로 부적합 소스를 재활성화하지 않는다.
